00. Introducción a las Hojas de Estilo en Cascada (CSS)

Las hojas de estilo en cascada (Cascading Style Sheets, CSS) se utilizan en el desarrollo web moderno para dotar de presentación, diseño visual y adaptabilidad a las páginas escritas en HTML.

¿Por qué surgieron las hojas de estilo?

Limitaciones de HTML

HTML fue concebido para estructurar datos (párrafos, listas, tablas), no para el diseño tipográfico ni la maquetación visual avanzada.

Código enredado

Antes de CSS, los atributos de estilo se incrustaban dentro del HTML, haciendo que el marcado fuera confuso y difícil de mantener.

Coste de mantenimiento

Cambiar el aspecto de un portal de 50 páginas requería modificar manualmente 50 archivos. CSS permite cambiarlo todo con un único archivo externo.

Ante esta situación, el organismo internacional W3C (World Wide Web Consortium) promovió la separación radical entre la estructura de contenidos (HTML) y la capa de presentación (CSS).

El potencial del diseño con CSS: Zen Garden

Un ejemplo paradigmático de la potencia de las hojas de estilo se encuentra en CSS Zen Garden, donde exactamente el mismo documento HTML adquiere decenas de aspectos y layouts radicalmente distintos simplemente enlazando diferentes hojas de estilo CSS.

El Principio de Cascada y Herencia

La denominación "en cascada" hace referencia a que las reglas de estilo se aplican a los elementos descendientes siguiendo un estricto criterio de herencia y precedencia. Por ejemplo, al definir una fuente en el elemento <body>, todos los párrafos, listas y encabezados hijos heredarán dicha tipografía de forma automática sin necesidad de redefinirla.

Los estándares actuales de CSS3 y CSS4 introducen diseño flexible (Flexbox), rejillas bidimensionales (CSS Grid), variables nativas (CSS Custom Properties), animaciones fluidas y consultas de medios (Media Queries) para diseño responsivo en cualquier resolución de pantalla.

Validación oficial del código CSS (W3C)

Al igual que ocurre con HTML, el consorcio W3C proporciona un validador oficial y gratuito para verificar la corrección sintáctica de nuestras reglas CSS en http://jigsaw.w3.org/css-validator/.

Cuando una hoja de estilo cumple las especificaciones sin errores de sintaxis, se puede incluir el sello de conformidad W3C CSS en la web.
