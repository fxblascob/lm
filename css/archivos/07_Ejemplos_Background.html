07. Fondos en CSS (Backgrounds)

Las propiedades de fondo permiten controlar el aspecto visual detrás del contenido de cualquier elemento HTML. Desde colores planos y gradientes modernos hasta imágenes fijas con efectos de desplazamiento, CSS ofrece un control exhaustivo de cada capa de fondo.

1. Propiedades de Fondo Fundamentales

background-color

Define el color de relleno del contenedor. Admite nombres (coral), HEX (#0d6efd), RGB y RGBA con transparencia.

background-color: rgba(13, 110, 253, 0.15);
background-image

Carga una o más imágenes mediante la función url() o gradientes generados por CSS.

background-image: url("fondo.jpg");
background-repeat

Controla la repetición del mosaico: repeat, no-repeat, repeat-x o repeat-y.

background-repeat: no-repeat;
background-position

Posición inicial de la imagen dentro de la caja: center, top right, o en coordenadas porcentuales/píxeles.

background-position: center top;
background-size

Escala la imagen: cover (llena el área recortando), contain (se ajusta completa sin cortes) o dimensiones fijas.

background-size: cover;
background-attachment

Determina si el fondo se desplaza con el scroll (scroll) o se queda anclado a la pantalla (fixed, efecto Parallax).

background-attachment: fixed;
Propiedad Abreviada (Shorthand) background

Permite condensed en una única declaración todas las propiedades de fondo en el orden canónico: 

/* color | image | position / size | repeat | attachment */
.hero-banner {
    background: #0d6efd url("hero.webp") center / cover no-repeat fixed;
}
