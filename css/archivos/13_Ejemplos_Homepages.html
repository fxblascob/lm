13. Maquetación de Páginas Web (Homepages)

La maquetación (layout) es el arte de estructurar armónicamente los diferentes bloques de un sitio web: cabeceras, menús de navegación, barras laterales, áreas de contenido y pies de página. Comprender su evolución histórica y los estándares actuales es clave para cualquier desarrollador frontend.

1. Evolución Histórica de los Sistemas de Maquetación

1995 - 2002
Maquetación con Tablas <table>

Se usaban tablas HTML invisibles anidadas para forzar columnas. Totalmente obsoleto: código farragoso, nula accesibilidad e imposible adaptación a pantallas móviles.

2002 - 2015
Maquetación con Flotantes (float)

Uso de divisiones (<div>) con float: left y porcentajes. Requirió complejos trucos de clearfix y cálculos matemáticos para compensar márgenes.

Actualidad (Estándar)
Flexbox y CSS Grid

Sistemas nativos bidimensionales y unidimensionales. Alineación perfecta, reordenación semántica, espacios automáticos con gap y diseño 100% responsive sin trucos.

2. Anatomía de una Portada (Homepage)

<header> + <nav> — Cabecera corporativa, logotipo y barra de navegación
<aside> Barra lateral (Sidebar), filtros o enlaces secundarios
<main> Contenido principal, artículos destacados y llamadas a la acción
<footer> — Pie de página, créditos legales, enlaces y redes sociales
