08. Tipografía y Estilos de Texto en CSS

El texto es el medio principal de comunicación en la web. CSS distingue claramente entre las propiedades que definen la fuente o tipografía (familia, peso, tamaño) y las propiedades que dan formato y alineación al texto (espaciado, interlineado, transformación y decoraciones).

Propiedades de Fuente (font-*)
  • font-family: Pila tipográfica con familias de respaldo (ej: system-ui, -apple-system, sans-serif).
  • font-size: Tamaño del glifo. Se recomienda el uso de rem para accesibilidad (ej: 1rem = 16px).
  • font-weight: Grosor o peso del trazo: normal (400), bold (700) o de 100 a 900.
  • font-style: Inclinación del carácter: normal, italic (cursiva real) u oblique.
font: italic 700 1.25rem/1.5 system-ui, sans-serif;
Propiedades de Texto (text-* y espaciado)
  • color: Color de los caracteres tipográficos (HEX, RGB, HSL).
  • text-align: Alineación horizontal: left, center, right, justify.
  • text-decoration: none (quitar subrayado a links), underline, line-through.
  • text-transform: uppercase (MAYÚSCULAS), lowercase o capitalize.
  • line-height: Interlineado vertical. Se recomienda valor sin unidad (ej: 1.6).
  • letter-spacing: Espaciado horizontal entre letras individuales.
Pauta de accesibilidad WCAG para lectura ergonómica: Para garantizar una óptima legibilidad en pantallas digitales, se recomienda un line-height de entre 1.5 y 1.7, contrastes de color texto/fondo con ratio mínimo de 4.5:1 y una longitud máxima de línea de aproximadamente 65 a 75 caracteres (max-width: 65ch;).
