Tipos de hojas de estilo

Una hoja de estilos contiene datos de formato relativos a los elementos definidos en la página HTML. Por lo tanto, ambos (documento HTML y hoja de estilo) deben estar relacionados de alguna manera. Existen tres maneras de utilizar hojas de estilo:

Tres formas de insertar CSS

  • Estilo en línea
  • Hojas de estilo internas
  • Hojas de estilo externas
  1. Estilo en línea: Aplicar estilos directamente a elementos HTML. De esta manera se escribe el código CSS dentro del atributo style de la etiqueta HTML en cuestión. Por ejemplo, para aplicar un estilo css a un párrafo: 
    <p style="color:sienna;margin-left:20px;">HOLA</p>
  2. Hojas de estilos internas. Se utilizan para aplicar estilos a la página en la cual se utiliza. El código de la hoja de estilo se ubicará en la cabecera de la página web, entre las etiquetas <style> y </style> 
    <head>
    <style>
        hr {color:sienna;}
        p {margin-left:20px;}
        body {background-image:url("images/back40.gif");}
    </style>
</head>
  3. Hojas de estilos externas. Se utilizan para aplicar el mismo formato a varias páginas de un portal. Se definen en un archivo externo que será consultado por todas las páginas HTML del sitio web, reutilizando por tanto el código. Para ello se escribirá el código CSS en un documento externo con extensión css. Posteriormente se vinculará a la página web mediante la utilización de la siguiente etiqueta en la cabecera del documento HTML en cuestión: 
    <link rel="stylesheet" type="text/css" href="nombre_archivo_css.css">

Orden de los estilos en Cascada

¿Qué estilo se usará cuando se ha especificado más de un estilo para un elemento de HTML?

Los estilos irán en cascada en el siguiente orden de prioridad, de menos a más.

  1. Hoja de estilos externa
  2. Hoja de estilos interna
  3. Estilo en línea (directamente en un elemento HTML)

Un estilo en línea (dentro de un elemento HTML) tiene la prioridad mayor lo que quiere decir que sobrescribirá un estilo definido en una hoja de estilo interna (en la cabecera) o en una hoja de estilo externa.

Nota: Si el link de la hoja de estilo externa está después de la hoja de estilo interna, la externa anulará la interna.
