01. Tipos de Hojas de Estilo en CSS

El lenguaje CSS (Cascading Style Sheets) fue diseñado con un principio clave de la arquitectura web: separar el contenido y la estructura semántica (HTML) de la presentación y el diseño visual (CSS). Para aplicar reglas de estilo a un documento web existen tres métodos fundamentales, además de directivas modulares de importación.

Principio de separación de responsabilidades: Mantener el diseño en archivos independientes no solo hace el código más limpio y legible, sino que acelera notablemente la carga de las páginas web gracias a la memoria caché de los navegadores.

Tres Formas de Insertar CSS

Método 1 Estilo en línea (Inline style) Atributo style

Se define directamente dentro de la etiqueta HTML deseada mediante el atributo global style. El valor del atributo contiene una o más declaraciones CSS separadas por punto y coma.

Ejemplo HTML: 
<p style="color: #0d6efd; margin-left: 20px; font-weight: bold;">
    Este párrafo tiene estilos aplicados en línea.
</p>
Ventaja: Inmediatez para pruebas rápidas y maquetación de correos electrónicos (HTML emails).
Desventaja: Rompe la separación de código, no es reutilizable y tiene una especificidad muy alta difícil de sobrescribir.
Método 2 Hoja de estilo interna o incrustada (Embedded) Elemento <style>

Las reglas CSS se escriben dentro del elemento <style> ubicado en la cabecera (<head>) del documento HTML. Afectan a todos los elementos coincidentes de esa página en particular.

Ejemplo HTML: 
<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Página con estilos internos</title>
    <style>
        body {
            background-color: #f8f9fa;
            font-family: system-ui, sans-serif;
        }
        h1 {
            color: #0d6efd;
            border-bottom: 2px solid #dee2e6;
        }
        p {
            line-height: 1.6;
            margin-bottom: 1rem;
        }
    </style>
</head>
Ventaja: Ideal para estilos únicos de una página o para inyectar CSS crítico (Critical CSS) mejorando la velocidad de carga.
Desventaja: No se comparte entre diferentes páginas del sitio web; cambiar un estilo global requeriría editar archivo por archivo.
Método 3 Hoja de estilo externa (External stylesheet) — Estándar recomendado Elemento <link>

Es la mejor práctica indiscutible en desarrollo web. El código CSS se redacta en un archivo independiente con extensión .css y se vincula a cualquier página HTML mediante la etiqueta <link> dentro de <head>.

1. En el documento HTML: index.html 
<head>
    <meta charset="UTF-8">
    <title>Mi sitio web</title>
    <link rel="stylesheet" href="css/estilos.css">
</head>
En HTML5 el atributo type="text/css" es obsoleto y redundante, pues CSS es el estándar por defecto.
2. En el archivo CSS: css/estilos.css 
body {
    margin: 0;
    font-family: system-ui, sans-serif;
    color: #212529;
}

.boton-principal {
    background-color: #0d6efd;
    color: #ffffff;
    border-radius: 0.375rem;
}
Por qué es el método profesional: Permite cambiar el aspecto corporativo completo de miles de páginas modificando un único archivo. Además, el navegador web guarda el archivo .css en su memoria caché tras la primera visita, por lo que las siguientes páginas cargan de forma casi instantánea sin volver a descargar los estilos.

La directiva de importación modular: @import

CSS permite importar hojas de estilo dentro de otras hojas de estilo mediante la regla @import. Debe colocarse obligatoriamente en la primera línea del archivo CSS o al inicio del bloque <style>, antes de cualquier otra regla. 

/* En el archivo principal estilos.css */
@import url("reset.css");
@import url("tipografia.css");
@import url("botones.css");

/* Reglas generales posteriores */
main {
    padding: 2rem;
}
Aviso de rendimiento: @import carga los archivos de forma secuencial (uno tras otro), generando un cuello de botella en la red. En proyectos de producción modernos se prefiere usar múltiples etiquetas <link> en HTML (que cargan en paralelo) o herramientas de compilación/empaquetado (como Vite o Webpack).

Comparativa de Métodos

Método Ubicación Ámbito Aprovecha Caché Recomendación
En línea (Inline) Atributo style="..." Elemento individual No Uso esporádico / Emails
Interna (Embedded) Elemento <style> en <head> Una sola página HTML No (va en el HTML) Pruebas / CSS crítico
Externa (Linked) Archivo .css + etiqueta <link> Múltiples páginas del portal Sí (Excelente) Estándar profesional
Regla @import Primera línea dentro de un archivo CSS Según el archivo destino Sí (el subarchivo) Evitar por lentitud

Orden de Prioridad en Cascada

¿Qué ocurre si para un mismo elemento (por ejemplo, un <p>) se declaran reglas contradictorias en los diferentes tipos de hojas? El navegador resuelve el conflicto evaluando el orden de la cascada:

1. Prioridad Base Hoja Externa

Aplica los estilos generales de todo el sitio web. Es la base de diseño corporativo.

2. Prioridad Intermedia Hoja Interna

Sobrescribe a la hoja externa si está declarada después en el <head> o tiene selectores más específicos.

3. Máxima Prioridad Estilo en Línea

El estilo en línea dentro de la etiqueta HTML sobrescribe tanto a hojas internas como externas para esa propiedad concreta.

Regla del orden en el documento: Entre hojas de estilo externas e internas, en caso de igualdad de especificidad, la última que aparezca leída en el código HTML prevalecerá sobre las anteriores. Por este motivo, siempre enlazamos librerías externas como Bootstrap antes que nuestro propio archivo estilos.css.
