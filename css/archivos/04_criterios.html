04. Criterios de Selección y Combinadores

En proyectos web reales, dar estilo a una página requiere apuntar a elementos basándose en cómo se relacionan en el árbol del DOM (padres, hijos, hermanos) o en los valores de sus atributos HTML. Los combinadores y selectores avanzados proporcionan esta precisión quirúrgica.

1. Combinadores de Relación Jerárquica

Un combinador une dos selectores simples para definir una relación espacial o jerárquica entre ellos:

Descendiente (Espacio) A B { ... }

Selecciona todos los elementos B que se encuentren dentro de A, sin importar el nivel de anidamiento o profundidad. 

/* Cualquier <p> dentro de <article> */
article p {
    line-height: 1.7;
}
Hijo Directo (>) A > B { ... }

Selecciona solo los elementos B que sean hijos inmediatos de A. Si hay una etiqueta intermedia, no se aplica. 

/* Solo los <li> hijos directos de <ul> */
ul > li {
    list-style-type: square;
}
Hermano Adyacente (+) A + B { ... }

Selecciona el elemento B que aparece inmediatamente después de A, compartiendo el mismo elemento padre. 

/* El primer párrafo que sigue a un <h2> */
h2 + p {
    font-size: 1.2rem;
    color: #495057;
}
Hermano General (~) A ~ B { ... }

Selecciona todos los hermanos B que se encuentren después de A al mismo nivel jerárquico, aunque no sean contiguos. 

/* Todos los <p> que van tras un <h2> */
h2 ~ p {
    margin-bottom: 1.5rem;
}

2. Pseudoclases Estructurales de Posición: :nth-child()

La pseudoclase :nth-child(fórmula) permite seleccionar elementos según su posición matemática exacta entre sus hermanos. 

/* 1. Palabras clave: odd (impar: 1, 3, 5...) y even (par: 2, 4, 6...) */
tbody tr:nth-child(odd)  { background-color: #f8f9fa; } /* Cebrado de tablas */
tbody tr:nth-child(even) { background-color: #ffffff; }

/* 2. Ciclos periódicos: cada 3 elementos */
li:nth-child(3n) { border-bottom: 2px solid #0d6efd; }

/* 3. Primer y último elemento */
li:first-child { font-weight: bold; }
li:last-child  { color: #dc3545; }
Diferencia entre :nth-child() y :nth-of-type(): :nth-child(2) selecciona el elemento si es el segundo hijo en total de su padre (sin importar la etiqueta). En cambio, p:nth-of-type(2) busca específicamente el segundo párrafo, ignorando encabezados o imágenes intermedias.

3. Selectores de Atributos HTML

Permiten aplicar estilos a elementos en función de la existencia o del valor específico de sus atributos (como href, type, target, src):

Selector Ejemplo Significado / Caso de Uso
[attr] a[target] Tiene el atributo presente, sin importar su valor.
[attr="valor"] input[type="email"] Coincidencia exacta con el valor indicado.
[attr^="valor"] a[href^="https://"] El valor comienza por esa cadena (ej: enlaces seguros HTTPS).
[attr$="valor"] a[href$=".pdf"] El valor termina en esa extensión (ej: colocar icono a descargas PDF).
[attr*="valor"] a[href*="google"] El valor contiene la subcadena en cualquier posición.
[attr~="valor"] [class~="activo"] El atributo contiene una lista separada por espacios donde figura la palabra.
[attr|="valor"] [lang|="es"] Comienza por el valor seguido de un guion (ej: es-ES, es-MX).

Ejemplo Práctico en Formularios y Enlaces

/* 1. Estilo para enlaces que abren en nueva pestaña */
a[target="_blank"]::after {
    content: " ↗";
    font-size: 0.85em;
}

/* 2. Añadir icono automático a enlaces de descarga PDF */
a[href$=".pdf"]::before {
    content: "📄 ";
}

/* 3. Inputs obligatorios resaltados en formularios */
input[required] {
    border-left: 4px solid #dc3545;
}

4. Selectores Lógicos Modernos: :not() e :is()

Negación con :not(selector)

Selecciona todos los elementos que no cumplan la condición indicada:

/* Todos los botones excepto el primario */
button:not(.btn-primary) {
    opacity: 0.8;
}
Agrupación con :is()

Simplifica selectores largos y repetitivos en una sola línea legible:

/* Encabezados dentro de cabecera o artículo */
:is(header, article) h1 {
    color: #0d6efd;
}
