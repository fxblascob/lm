09. Enlaces y Tablas en CSS

Los hipervínculos son el eje de navegación de la web, y las tablas representan datos tabulares estructurados. CSS permite transformar enlaces básicos en botones interactivos y barras de navegación completas, así como dotar a las tablas de diseños limpios, cebrados y adaptados a dispositivos móviles.

1. Estilización de Enlaces y Menús

Estados Dinámicos (LVHA)

Control de la experiencia de usuario según la interacción:

  • a:link { color: #0d6efd; }
  • a:visited { color: #6c757d; }
  • a:hover { text-decoration: underline; }
  • a:active { color: #fd7e14; }
Enlaces tipo Botón (Button Boxes)

Transforma un enlace en línea en un botón pulsable ergonómico:

a.boton {
    display: inline-block;
    padding: 0.5rem 1.25rem;
    background-color: #0d6efd;
    color: #ffffff;
    text-decoration: none;
    border-radius: 0.375rem;
    transition: background 0.2s;
}
Barras de Navegación

Construidas semánticamente mediante listas no ordenadas:

/* Menú horizontal con flexbox */
nav ul {
    list-style: none;
    display: flex;
    gap: 1rem;
    padding: 0;
}

2. Propiedades de Tablas en CSS

border-collapse: collapse;

Por defecto, las tablas HTML separan los bordes de cada celda. La propiedad border-collapse: collapse; unifica los bordes adyacentes en una única línea delgada, logrando un diseño moderno y compacto.

table { border-collapse: collapse; width: 100%; }
Cebrado y Resaltado (Zebra Striping)

Mejora la velocidad de escaneo visual de datos alternando el color de fondo de las filas pares con :nth-child(even) y resaltando la fila sobre la que pasa el ratón con tr:hover.

tbody tr:nth-child(even) { background: #f8f9fa; }
