Ejercicio 1 Fundamentos Resuelto
#ej_01

Estilos en línea (Atributo style)

Partiendo del documento HTML base, aplica un estilo CSS al primer párrafo utilizando el método de estilo en línea mediante el atributo style. El formato consistirá en asignar color verde y un tamaño de fuente de 15 puntos.

Solución Implementada:
Solución HTML 
<!-- En el archivo ejercicio1.html -->
<p style="color: green; font-size: 15pt;">
    En un lugar de la Mancha, de cuyo nombre no quiero acordarme...
</p>
<p>
    No ha mucho tiempo que vivía un hidalgo de los de lanza en astillero...
</p>
Explicación: El atributo style="..." añade estilos directamente al elemento sin necesidad de reglas ni selectores, con la máxima especificidad (1,0,0,0) frente a hojas externas o internas.

Ejercicio 2 Fundamentos Resuelto
#ej_02

Hoja de estilo interna (<style> en <head>)

Manteniendo el estilo en línea del ejercicio 1 en el primer párrafo, añade una hoja de estilo interna en la cabecera <head> que asigne a todos los párrafos (p) color rojo y tamaño de fuente de 8 puntos.

Solución Implementada:
Solución HTML 
<head>
    <meta charset="UTF-8">
    <title>Ejercicio 2</title>
    <style>
        p {
            color: red;
            font-size: 8pt;
        }
    </style>
</head>
<body>
    <p style="color: green; font-size: 15pt;">Primer párrafo (prevalece style en línea)</p>
    <p>Segundo párrafo (aplica estilo de la hoja interna)</p>
</body>
Explicación: La regla de tipo p tiene especificidad (0,0,0,1), por lo que es superada por el estilo en línea (1,0,0,0) del primer párrafo.

Ejercicio 3 Fundamentos Resuelto
#ej_03

Hoja de estilo externa y orden de cascada

Crea un archivo externo llamado estilos.css con reglas para los párrafos (color azul, sangría de 2em y alineación derecha). Guarda una copia del ejercicio anterior como ejercicio3.html y vincula la hoja externa. Comprueba qué ocurre al enlazar la hoja externa antes o después de la hoja interna.

Solución Implementada:
Solución HTML Solución CSS 
/* Archivo 03.css */
p { 
    color: blue;
    text-indent: 2em;
    text-align: right;
}

<!-- En 03.html: Si cargamos externa antes de style -->
<link rel="stylesheet" href="03.css">
<style>
    p { color: red; font-size: 8pt; }
</style>
<!-- Prevalece color: red porque la etiqueta <style> va después -->
Explicación: El algoritmo de cascada resuelve conflictos de igual especificidad priorizando la última declaración en el orden de origen.

Selector de Identificador (#id)

Ejercicio 5 Selectores CSS Resuelto
#ej_05

Selector de Clase y Selección de Elementos Impares

Partiendo de codigo_html_base.html, aplica un estilo a los párrafos impares del documento. El estilo asignará color azul y tamaño de fuente de 7 puntos. Puedes resolverlo mediante una clase (class="impar") o utilizando la pseudoclase estructural :nth-child(odd) en una hoja externa ejercicio5.css.

Solución Implementada:
Solución HTML Solución CSS 
/* Archivo 05.css */
p:nth-child(odd) {
    color: blue; 
    font-size: 7pt;    
}

/* O mediante clases HTML: */
.impar {
    color: blue;
    font-size: 7pt;
}
Explicación: El selector de clase tiene especificidad (0,0,1,0), idéntica a la pseudoclase :nth-child().

Ejercicio 6 Selectores CSS Resuelto
#ej_06

Pseudoclases de Enlace (:link, :visited, :hover, :active)

Aplica estilos en ejercicio6.css a todos los hipervínculos del documento base siguiendo la regla mnemotécnica LVHA: enlaces no visitados en rojo (red), visitados en verde (green), al situar el ratón encima en azul (blue) y en el instante de hacer clic en amarillo (yellow).

Solución Implementada:
Solución HTML Solución CSS 
/* Archivo 06.css */
a:link    { color: red; }    /* Enlace no visitado */
a:visited { color: green; }  /* Enlace ya visitado */
a:hover   { color: blue; }   /* Cursor encima del enlace */
a:active  { color: yellow; } /* Al seleccionar/hacer clic */
a:focus   { color: brown; }  /* Navegación por teclado */
Explicación: Añadir :focus garantiza accesibilidad para usuarios que navegan mediante tabulación de teclado.

Ejercicio 7 Selectores CSS Resuelto
#ej_07

Pseudoelemento ::first-letter (Letra Capital)

Aplica estilos en ejercicio7.css para crear letras capitulares tipográficas: la primera letra de cada párrafo debe tener un tamaño de 18 puntos, y la primera letra de cada encabezado <h3> debe tener un tamaño de 22 puntos.

Solución Implementada:
Solución HTML Solución CSS 
/* Archivo 07.css */
h3::first-letter { 
    font-size: 22pt;
}
p::first-letter {
    font-size: 18pt;
}
Explicación: Las propiedades aplicables a ::first-letter están acotadas a tipografía, color, fondos, márgenes y flotación (como float: left para letras capitulares encajadas).

Ejercicio 8 Herencia y Cascada Resuelto
#ej_08

Herencia y forzado con inherit

Aplica al elemento body letra de color rojo y un borde sólido de 3px en ejercicio8.css. Observa que los párrafos heredan el color pero no el borde. A continuación, añade la regla border: inherit; a los párrafos para forzar la herencia del borde.

Solución Implementada:
Solución HTML Solución CSS 
/* Archivo 08.css */
body {
    color: red;
    border-style: solid;
    border-width: 3px;
    border-color: red;
}
p {
    border: inherit;
}
Explicación: El valor inherit computa el valor de la propiedad del padre directo y lo aplica al elemento hijo.

Ejercicio 9 Maquetación Clásica Resuelto
#ej_09

Maquetación clásica con flotantes (float y clear)

Guarda el HTML base como ejercicio9.html agrupando el contenido en dos capas contenedoras (#capa1 y #capa2). Elabora cuatro hojas externas (ejercicio9a.css a 9d.css) comprobando las combinaciones de flotación: 9a (Capa 1 flotando a la derecha), 9b (Capa 1 flotando a la izquierda), 9c (Ambas capas flotando a izquierda y derecha), y 9d (Capa 1 a la izquierda y Capa 2 con clear: both).

Solución Implementada:
09a (HTML) 09a (CSS) 09b (HTML) 09b (CSS) 09c (HTML) 09c (CSS) 09d (HTML) 09d (CSS) 
/* 09c.css: Columnas enfrentadas */
#capa1 { float: left; width: 48%; background-color: yellow; }
#capa2 { float: right; width: 48%; background-color: grey; }

/* 09d.css: Segunda capa despejando flotación */
#capa1 { float: left; width: 50%; background-color: yellow; }
#capa2 { clear: both; background-color: grey; }
Explicación: Los elementos con float salen del flujo normal del documento. Las cajas no flotadas adyacentes fluyen alrededor de su caja límite.

Ejercicio 10 Maquetación Clásica Resuelto
#ej_10

Análisis de esquema web con float y clear

Analiza la arquitectura clásica de un sitio web con cabecera, dos columnas adyacentes y pie de página. Responde a las tres preguntas técnicas en un documento ejercicio10.txt:

  1. ¿Cuántas capas se emplean en el HTML, cuáles son sus nombres y si usan clases o identificadores?
  2. ¿Qué tipo de hoja de estilos se emplea y qué ventajas ofrece para pruebas?
  3. ¿Qué mecanismo CSS permite que las columnas se coloquen lado a lado y qué propiedad evita que el pie de página se solape?

Solución Implementada:
Solución HTML Versión moderna (HTML) 
/* Respuestas modelo para ejercicio10.txt */
1. Se utilizan 4 capas principales: header, nav, section y footer, identificadas habitualmente por clases (.header, .nav, .section, .footer) o IDs (#header, #nav...).
2. Se suele usar hoja interna para ejemplos autocontenidos didácticos, aunque en producción es preferible externa por mantenibilidad.
3. Se colocan una junto a otra con float: left (con anchos complementarios, ej. 25% y 75%), y el pie de página utiliza clear: both para no solaparse.
Explicación: Hoy en día, este patrón se resuelve con Flexbox o CSS Grid sin necesidad de clear: both ni desbordamientos.

Ejercicio 13 Responsive y Grid Resuelto
#ej_13

Diseño web adaptativo con Media Queries

Partiendo de la plantilla HTML proporcionada, implementa una hoja de estilo adaptativa con reglas @media que restructure el layout según el ancho del dispositivo: disposición a una sola columna en pantallas móviles estrechas y dos columnas en pantallas de escritorio medianas y grandes.

Solución Implementada:
Solución HTML Solución CSS 
/* Extracto de 13_adaptativo.css */
@media screen and (max-width: 600px) {
    .columna {
        width: 100%;
        float: none;
    }
}
@media screen and (min-width: 601px) {
    .lateral { width: 30%; float: left; }
    .principal { width: 70%; float: left; }
}
Explicación: Siempre debe incluirse el meta tag <meta name="viewport" content="width=device-width, initial-scale=1.0"> para que el navegador móvil no aplique zoom de escritorio automático.

Ejercicio 14 Responsive y Grid Resuelto
#ej_14

Reorganización de cajas con Media Queries y CSS Grid

Utilizando las cuatro cajas del documento base proporcionado, elabora una hoja de estilo con Media Queries o CSS Grid que configure tres disposiciones visuales según la anchura de la ventana:

  • Móvil (< 600px): 1 columna apilada verticalmente.
  • Tablet (600px - 992px): Rejilla 2x2 equilibrada.
  • Escritorio (> 992px): Las cuatro cajas alineadas en horizontal o en distribución asimétrica.

Solución Implementada:
Solución completa HTML+CSS 
/* 14_media_queries_grid.html */
@media screen and (min-width: 600px) and (max-width: 900px) {
    .caja { width: 48%; float: left; margin: 1%; }
}
@media screen and (min-width: 901px) {
    .caja { width: 23%; float: left; margin: 1%; }
}
Explicación: Modernizado con CSS Grid: grid-template-columns: repeat(auto-fit, minmax(220px, 1fr)); logra el mismo resultado de forma 100% fluida.

Ejercicio 15 Responsive y Grid Resuelto
#ej_15

Distribución flexible con Flexbox (flex-grow y flex-wrap)

Con el mismo documento base de 4 cajas, implementa un contenedor Flexbox (display: flex; flex-wrap: wrap;) que satisfaga estas condiciones:

  • Las dos cajas centrales ocupan el doble de tamaño que las laterales (proporción flex-grow: 2 frente a flex-grow: 1).
  • Cajas laterales con fondo gris y centrales amarillo-anaranjado.
  • Anchura mínima de 200px para las laterales y 300px para las centrales (flex-basis o min-width) para forzar su redistribución fluida en pantallas pequeñas.

Solución Implementada:
Solución completa HTML+CSS 
/* 15_flexbox.html */
.flex-container {
    display: flex;
    flex-wrap: wrap;
    gap: 15px;
}
.lateral {
    flex: 1 1 200px;
    background-color: #e0e0e0;
}
.central {
    flex: 2 1 300px;
    background-color: #ffd166;
}
Explicación: La notación abreviada flex: [grow] [shrink] [basis] condensa los tres factores de dimensionamiento flexible en una sola declaración.

Ejercicio 16 Framework Bootstrap Resuelto
#ej_16

Maquetación adaptativa con el sistema de rejilla de Bootstrap 5

Partiendo del documento de 4 cajas, elimina los estilos manuales de posición y aplica las clases de rejilla de 12 columnas de Bootstrap 5 (container, row, col-*) cumpliendo:

  • En pantallas grandes (lg o superior ≥ 992px): las 4 cajas en una sola fila (3 columnas cada una: col-lg-3).
  • En pantallas medianas (sm y md ≥ 576px): las cajas agrupadas de 2 en 2 (6 columnas cada una: col-sm-6).
  • En pantallas móviles (< 576px): cada caja ocupa el ancho completo (col-12).
  • Separación uniforme con gutters (g-3).

Solución Implementada:
Solución interactiva Bootstrap 
<!-- Solución con Bootstrap 5.3 -->
<div class="container my-4">
    <div class="row g-3">
        <div class="col-12 col-sm-6 col-lg-3">
            <div class="p-4 bg-info-subtle border rounded shadow-sm text-center">Caja 1</div>
        </div>
        <div class="col-12 col-sm-6 col-lg-3">
            <div class="p-4 bg-warning-subtle border rounded shadow-sm text-center">Caja 2</div>
        </div>
        <div class="col-12 col-sm-6 col-lg-3">
            <div class="p-4 bg-success-subtle border rounded shadow-sm text-center">Caja 3</div>
        </div>
        <div class="col-12 col-sm-6 col-lg-3">
            <div class="p-4 bg-danger-subtle border rounded shadow-sm text-center">Caja 4</div>
        </div>
    </div>
</div>
Explicación: Con Bootstrap no es necesario escribir Media Queries manuales para orquestar la disposición en columnas entre dispositivos.

Ejercicio 17 Framework Bootstrap Resuelto
#ej_17

Diseño ergonómico de formularios con componentes Bootstrap 5

Descarga la plantilla de formulario HTML sin estilizar y aplícale las clases semánticas de Bootstrap 5 para crear una interfaz limpia y ergonómica:

  • Campos de texto, email y contraseña con form-control y sus etiquetas correspondientes con form-label.
  • Agrupaciones de formulario con rejilla row g-3.
  • Checkboxes y radios con form-check e form-check-input.
  • Selectores estilizados con form-select.
  • Botones de acción claros con btn btn-primary.

Solución Implementada:
Solución interactiva formulario 
<!-- Formulario estilizado con Bootstrap 5 -->
<form class="row g-3">
    <div class="col-md-6">
        <label for="inputEmail" class="form-label">Email</label>
        <input type="email" class="form-control" id="inputEmail">
    </div>
    <div class="col-md-6">
        <label for="inputPassword" class="form-label">Contraseña</label>
        <input type="password" class="form-control" id="inputPassword">
    </div>
    <div class="col-12">
        <div class="form-check">
            <input class="form-check-input" type="checkbox" id="gridCheck">
            <label class="form-check-label" for="gridCheck">Acepto los términos</label>
        </div>
    </div>
    <div class="col-12">
        <button type="submit" class="btn btn-primary px-4 shadow-sm">Registrarse</button>
    </div>
</form>
Explicación: El uso de form-label y for="..." enlazado al id="..." del control garantiza máxima accesibilidad (a11y) y una amplia zona táctil en pantallas móviles.
