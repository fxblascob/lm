10. Imágenes y Bordes en CSS

El tratamiento de imágenes y el diseño de bordes definen la personalidad visual de una interfaz web. CSS moderno proporciona propiedades de ajuste como object-fit y aspect-ratio, esquinas redondeadas con border-radius y sombras profundas mediante box-shadow sin recurrir a trucos de edición de imagen.

1. Bordes, Sombras y Redondeo

border (Grosor, Estilo, Color)

Bordes sólidos, punteados o discontinuos:

border: 2px solid #0d6efd;
border-radius (Esquinas)

Curvatura de esquinas. Con 50% crea avatares o círculos perfectos:

border-radius: 0.5rem; /* o 50% */
box-shadow (Elevación)

Sombra para generar profundidad visual y sensación de elevación:

box-shadow: 0 4px 6px rgba(0,0,0,0.1);

2. Ajuste Profesional de Imágenes en CSS Moderno

object-fit: cover; — Cero Distorsión

Al fijar un ancho y alto a una imagen, esta suele achatarse o deformarse. Con object-fit: cover;, la imagen conserva su proporción de aspecto rellenando el contenedor y recortando los sobrantes suavemente (igual que background-size: cover). 

.avatar {
    width: 80px;
    height: 80px;
    object-fit: cover;
    border-radius: 50%;
}
aspect-ratio: 16 / 9; — Estabilidad CLS

Propiedad moderna estándar de CSS que reserva el espacio exacto de la imagen antes de que se descargue, evitando saltos bruscos en el contenido de la página (Cumulative Layout Shift). 

.miniatura-video {
    width: 100%;
    aspect-ratio: 16 / 9;
    object-fit: cover;
}
