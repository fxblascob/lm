06 Herencia y precedencia

Herencia y precedencia

Herencia

Hay propiedades CSS que afectan a los elementos definidos por un selector y también a sus descendientes. Por ejemplo, si se especifica la propiedad color en el body, los elementos que estén dentro de body heredarán dicha propiedad.

Sin embargo, también hay propiedades que no se heredan, como la propiedad border. Para conseguir que se herede dicha propiedad, se debe asignar el valor inherit a la propiedad que queremos que se herede del elemento padre.

Especificidad

En ocasiones, puede ocurrir que se definan dos reglas de estilo para un mismo elemento. Por ejemplo:

p#parrafo1 {
  font-size: 14pt;
}

p {
  font-size: 8pt;
}

En este caso, se indica que todos los párrafos deben tener tamaño de letra 8, mientras que el párrafo llamado párrafo1 debe tener tamaño 14. ¿Qué tamaño se aplicará al final al párrafo llamado párrafo1? Pues se aplicará tamaño 14, ya que esa regla es más concreta que la que se aplica a todos los párrafos en general.

En conclusión, puede decirse que cuanto más concreto es el selector, más valor tiene la regla. Así, el atributo id prevalecerá sobre el atributo class, y éste sobre cualquier selector simple. Además, los selectores simples se aplican por delante de las reglas heredadas.

Ubicación

Las reglas que aparecen en último lugar tienen más peso. Así, las reglas que se aplican localmente al elemento HTML se considera que aparecen después de las definidas en las hojas de estilo interna y externa. A continuación se muestra un ejemplo de esto:

<html>
  <head>
    <title>Ejemplo de conflictos con CSS</title>
	
    <style type="text/css">
      p {
        color: blue;
      }
      p.grupo {
        color: green;
      }
      p#tercero {
        color: red;
      }
    </style>
	
  </head>
	
  <body>
    <p>Este párrafo no pertenece a ninguna clase ni lleva
    ningún identificador. Estará escrito en azul.</p>
		
    <p class="grupo">Este párrafo pertenece a la clase
    "grupo" pero no lleva identificador. Estará escrito
    en verde.</p>
		
    <p class="grupo" id="tercero">Este párrafo pertenece
    a la clase "grupo" y tiene el identificador
    "tercero". Estará escrito en rojo.</p>
		
    <p style="color:#999999">Este párrafo se escribirá
    en gris, siguiendo el estilo definido localmente.</p>
	
  </body>
</html>
