03. Reglas y Selectores en CSS

Los selectores son el mecanismo que permite a CSS buscar y apuntar a los elementos específicos del documento HTML para aplicarles formato. Conocer su sintaxis, tipología y niveles de especificidad es la base indispensable de la maquetación web.

Selectores Básicos: Tipo, Universal y Agrupación

Tipo / Etiqueta p { ... }
Selector de Elemento

Afecta a todas las etiquetas del tipo indicado presentes en el documento HTML (ej: todos los párrafos <p>, encabezados <h1> o listas).

Universal * { ... }
Comodín Universal

El asterisco selecciona absolutamente todos los elementos del DOM. Se emplea en reglas de reseteo inicial, como normalizar el modelo de cajas.

Agrupación h1, h2, p { }
Selectores Múltiples

Separados por comas (,). Permite aplicar un mismo bloque de declaraciones a diferentes elementos sin duplicar código CSS (filosofía DRY). 

/* 1. Selector Universal: Reseteo de márgenes y modelo de cajas */
* {
    box-sizing: border-box;
    margin: 0;
}

/* 2. Selector de tipo */
p {
    color: #212529;
    line-height: 1.6;
}

/* 3. Agrupación de selectores */
h1, h2, h3 {
    color: #0d6efd;
    font-family: 'Segoe UI', sans-serif;
}

Selector de Identificador (#id)

En HTML, el atributo id asigna un nombre único a un elemento concreto. En CSS se apunta a él anteponiendo el símbolo almohadilla (#).

En HTML: 
<header id="cabecera-principal">
    <h1>Portal Educativo</h1>
</header>
En CSS: 
#cabecera-principal {
    background-color: #212529;
    padding: 1.5rem;
}
Buena práctica profesional: Un id debe ser único en todo el documento. Debido a que los identificadores tienen una especificidad muy alta en la cascada, en maquetación moderna se recomienda usar clases para estilizar y reservar los id para enlaces ancla (fragmentos URL) y JavaScript.

Selector de Clase (.class)

El atributo class es la herramienta fundamental del diseño modular: permite agrupar varios elementos bajo un mismo estilo y un solo elemento puede tener múltiples clases separadas por espacios. En CSS se referencia con un punto (.).

En HTML: 
<!-- Un elemento puede tener múltiples clases -->
<button class="btn btn-primario redondeado">
    Aceptar
</button>
En CSS: 
.btn {
    padding: 0.5rem 1rem;
}
.btn-primario {
    background-color: #0d6efd;
    color: white;
}
.redondeado {
    border-radius: 0.375rem;
}

Pseudoclases (Pseudo-classes)

Una pseudoclase (sintaxis :nombre con un solo dos puntos) clasifica a un elemento según su estado dinámico frente al usuario o su posición en la estructura: 

/* Estados de un enlace (Regla nemotécnica LVHA) */
a:link    { color: #0d6efd; }  /* Enlace sin visitar */
a:visited { color: #6f42c1; }  /* Enlace ya visitado en el historial */
a:hover   { color: #dc3545; }  /* Cursor encima del enlace */
a:active  { color: #fd7e14; }  /* En el instante de hacer clic */

/* Foco en inputs y accesibilidad */
input:focus {
    border-color: #0d6efd;
    outline: none;
}

/* Posición estructural */
li:first-child { font-weight: bold; }
li:last-child  { border-bottom: none; }
Regla mnemotécnica del orden de enlaces (LVHA): Para que los estilos respondan correctamente en todos los navegadores, las pseudoclases deben escribirse en este orden exacto: Link → Visited → Hover → Active (fácil de recordar como «LoVe HAte»).

Pseudoelementos (Pseudo-elements)

Un pseudoelemento permite dar estilo a una parte específica del elemento o generar contenido decorativo virtual sin agregarlo al código HTML. En la especificación moderna de CSS3 se escriben con doble dos puntos (::) para distinguirlos de las pseudoclases:

::before y ::after

Inserta contenido decorativo virtual antes o después del contenido del elemento. Requiere obligatoriamente la propiedad content:

.nota::before {
    content: "📌 ";
}
.enlace-ext::after {
    content: " ↗";
}
::first-letter y ::first-line

Estiliza tipográficamente la letra inicial (letra capitular) o la primera línea de un párrafo:

p::first-letter {
    font-size: 2.5rem;
    font-weight: bold;
    float: left;
}
p::first-line {
    font-variant: small-caps;
}

Guía Resumen de Selectores Básicos

Patrón de Selector Ejemplo Descripción de Selección
Universal * Selecciona absolutamente todos los elementos del documento.
Tipo / Etiqueta p, h1, div Selecciona todas las etiquetas coincidentes en la página.
Identificador #cabecera Selecciona el único elemento con el atributo id="cabecera".
Clase .alerta Selecciona todos los elementos con la clase class="alerta".
Combinado Etiqueta.Clase p.destacado Selecciona solo los párrafos que contengan la clase destacado.
Pseudoclase de Enlace a:hover Selecciona los enlaces cuando el cursor del ratón pasa sobre ellos.
Pseudoclase Estructural li:first-child Selecciona el primer elemento hijo dentro de su lista contenedora.
Pseudoelemento Virtual p::before Inserta un elemento virtual al comienzo del párrafo con content.
Pseudoelemento Tipográfico p::first-letter Aplica formato a la primera letra del texto del párrafo.
