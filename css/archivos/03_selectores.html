03 Reglas de estilos

Reglas de estilo

Una vez visto la estructura genérica de una regla de estilo en el punto anterior, podemos pasar a ver cómo se aplican dichas reglas. Partiremos del ejemplo siguiente:

p {
  color: red;  
}

En este caso, se aplicaría la regla de estilo color: red (que significa color de texto rojo) a todos los selectores indicados, en este caso los párrafos (elementos <p>) de la página HTML. Sin embargo, ¿sería posible actuar solamente en unos párrafos determinados y dejar el resto con otro color de letra? La respuesta es, obviamente, sí. Para ello se han desarrollado unos selectores especiales que responden a los nombres de identificador, clase, pseudo-clase y pseudo-elemento.

A menudo hay que aplicar un estilo a varios elementos, los podemos agrupar para hacer más compacto el código. Así en el ejemplo de abajo, todos los elemento <h1>, <h2> y <p> serían de color verde

h1,h2,p
{
color:green;
}

Identificadores - id

En HTML se puede definir un atributo llamado identificador (id), que tiene como fin asignar un nombre único a un elemento dentro de la página web. De esta manera, un elemento queda distinguido de todos los demás, ya que dentro de una página web no puede haber más de un elemento con el mismo identificador. Además, un elemento sólo puede tener un único identificador. Los identificadores son cadenas de letras y números que deben comenzar por una letra. En el ejemplo siguiente se puede ver cómo se identifica un párrafo con un identificador:

<p id="parrafo1">

Una vez que en el documento HTML hemos asignado un identificador a un elemento, podemos hacer referencia a dicho elemento en la hoja de estilo a través de su identificador. En este caso, puesto que se trata de un párrafo, la regla de estilo quedaría de la siguiente manera:

p#parrafo1 {font-size: 14pt;}
o bien:
#parrafo1 {font-size: 14pt;}

Genéricamente, si en HTML identificamos a un elemento <e id="identificador">, para aplicar una regla de estilo a dicho elemento se utilizará:

e#identificador {
  propiedad1: valor1;
  propiedad2: valor2;
  propiedad3: valor3;
  ...
}

Como puede observarse, se utiliza el nombre del elemento en cuestión seguido del símbolo almohadilla (#) y el nombre del identificador que le hayamos asignado.

Clases - class

En HTML se puede definir un atributo llamado clase (class), que tiene como fin agrupar varios elementos dentro de la página web. De esta manera, una clase hace referencia a un conjunto de elementos. Además, un elemento puede pertenecer a varias clases. Los nombres de clase son cadenas de letras y números que deben comenzar por una letra. En el ejemplo siguiente se puede ver cómo se define un elemento dentro de una clase:

<img src="mesa.jpg" class="muebles">

Para hacer que un elemento pertenezca a varias clases, éstas se separan por espacios:

<img src="cama.jpg" class="muebles habitacion">

Una vez que en el documento HTML hemos asignado una clase a un elemento, podemos hacer referencia a todos los elementos pertenecientes a una clase de la siguiente manera:

.muebles {
  border-width: 1px;
  border-color: red;
}           
.habitacion {
  border-width: 2px;
  border-style: dashed;
}

De esta manera, se crearía un borde rojo de un píxel en todos los elementos (imágenes, párrafos,...) que pertenecieran a la clase muebles y se crearía un borde de línea discontinua de 2 píxeles en todos los elementos de la clase habitacion. La imagen cama.jpg, al pertenecer a las dos clases, tendría un borde discontinuo rojo de 2 píxeles de grosor.

Como puede observarse, en la hoja de estilo se utiliza un punto seguido del nombre de la clase.

Ejercicio_CSS 5:

Pseudo-clases.

La sintaxis de pseudo-clases:

selector:pseudo-class {property:value;}

Las pseudo-clases clasifican a un elemento en función del estado del mismo. Normalmente se utilizan para los enlaces, y definen los eventos que hayan ocurrido: que el enlace esté sin visitar, que haya sido visitado, que el cursor del ratón se encuentre por encima, etc. Las más utilizadas se definen a continuación:

a:link    /*Enlace no visitado*/
a:visited /*Enlace ya visitado*/
a:hover   /*Cursor encima del Enlace*/
a:active  /*Al seleccionar el Enlace*/
a:focus   /*Enlaces seleccionados con el teclado*/

a:hover tiene que ir después de a:link y de a:visited
a:active tiene que ir después de a:hover

CSS clases pueden ser usadas con pseudoclases

selector.class:pseudo-class {property:value;}

a.red:visited {color:#FF0000;}

La Pseudo-clase :first-child

La pseudo-clase :first-child se refiere al elemento que es el primer hijo de otro elemento.

En el ejemplo de abajo el selector se refiere a cualquier <p> elemento que sea el primer hijo de cualquier otro elemento. Por lo que pondrá el primer párrafo en azul, por ser el primer hijo de <body>. Si hubiera una etiqueta antes, entre <body> y <p>, entonces ya no sería el primer hijo

<html>
<head>
<style>
p:first-child
{
color:blue;
}
</style>
</head>

<body>
<p>Esto es un párrafo</p>
<p>Esto es un párrafo</p>
</body>
</html>

Ejercicio_CSS 6:

Pseudo-elementos.

Los pseudo-elementos hacen referencia a algunas partes de los elementos de una página a los que HTML no otorga identidad propia. Solamente existen cuatro, que son:

:first-letter /*Primer carácter del elemento*/
:first-line   /*Primera línea del elemento*/
:before       /*Elemento anterior*/
:after        /*Elemento posterior*/

El ejemplo de abajo pone la primera letra de cada párrafo con un tamaño 16 y la primera línea la pone de color rojo y con mayúsculas de un tamaño menor

p:first-letter {
  font-size: 16pt;
} 
p:first-line
{
color:#ff0000;
font-variant:small-caps;
}

El ejemplo de abajo inserta la imagen smiley.gif delante de todos los <h1> y detrás de los <h2>

La propiedad content se utiliza solo con los pseudo-elementos ::before y ::after para insertar contenido como texto o imágenes.

h1:before {
   content:url(smiley.gif);
}

h2:after {
   content: " un texto cualquiera  ";
}
