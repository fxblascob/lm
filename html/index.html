00. Introducción a HTML

Introducción histórica

A finales de los años 80 se desarrolló el lenguaje de marcas SGML. En esa misma época, Tim Berners-Lee utilizó SGML para definir un nuevo lenguaje de etiquetas que denominó Hypertext Markup Language (HTML), con el objetivo de crear documentos transportables a través de Internet que permitieran el hipertexto.

Hoy en día la mayor parte de la información en Internet se transmite a través de documentos HTML. Lógicamente, desde 1989 hasta nuestros días HTML ha incorporado mejoras fundamentales como la ejecución de código en cliente (JavaScript), hojas de estilo en cascada (CSS), y elementos multimedia nativos (audio, vídeo y gráficos vectoriales).

En la actualidad, HTML sigue siendo la capa estructural esencial sobre la que se organizan las tecnologías de la plataforma web.

Normalización. Versiones de HTML

Los programas capaces de interpretar el código HTML y renderizarlo en pantalla son los navegadores (browsers): Firefox, Chrome, Edge, Safari, Opera, etc.

El papel del consorcio W3C: Para evitar que cada navegador utilizara dialectos incompatibles, Tim Berners-Lee fundó el World Wide Web Consortium (W3C) con el fin de fijar estándares abiertos en la industria.

Tras versiones históricas como HTML 4.01 y la etapa de XHTML 1.0, el estándar consolidado en la industria moderna es HTML5, complementado con las especificaciones del grupo WHATWG.

¿Qué es un documento HTML?

Una página web es fundamentalmente un documento de texto plano acompañado de una colección de etiquetas (tags) que indican al navegador:

  • Cómo estructurar y jerarquizar los bloques de texto (títulos, párrafos, listas).
  • De dónde obtener los recursos externos (imágenes, sonidos, vídeos) y cómo mostrarlos.
  • Cómo organizar los enlaces e hipervínculos que conectan unas páginas con otras.

Para crear documentos HTML no se requieren herramientas complejas; basta un editor de texto plano con soporte de código. En el módulo utilizaremos principalmente Visual Studio Code.

Formato de las etiquetas HTML

Las etiquetas se delimitan con los signos menor y mayor (< y >). Generalmente van por parejas: una de apertura (<etiqueta>) y otra de cierre con barra inclinada (</etiqueta>).

Ejemplo de etiquetas básicas de texto
<b>Este texto aparecerá en negrita.</b>
<i>Este texto aparecerá en cursiva.</i>
<strong>Texto con énfasis semántico importante.</strong>

Anidamiento de etiquetas

Es posible abrir etiquetas dentro de otras, siempre asegurando que se cierren en orden inverso al de apertura (estructura LIFO / árbol de elementos):

Ejemplo de anidamiento correcto
<p>
    Texto normal 
    <b>en negrita y <i>también en cursiva</i></b>.
</p>

Atributos de las etiquetas

Los atributos aportan propiedades, configuración o metadatos adicionales a una etiqueta. Se declaran siempre dentro de la etiqueta de apertura con la sintaxis nombre="valor":

Sintaxis general de atributos
<etiqueta atributo1="valor1" atributo2="valor2">
    Contenido del elemento
</etiqueta>

Recuerda que los valores de los atributos deben delimitarse siempre entre comillas.
