07. Listas en HTML5

Listas no ordenadas (<ul>), listas ordenadas (<ol>) con atributos modernos (start, reversed, type), listas anidadas y listas de descripción (<dl>).

Índice HTML Ejercicios

Las listas son elementos estructurales fundamentales en HTML. Permiten agrupar conjuntos de elementos relacionados, garantizando que lectores de pantalla y motores de búsqueda comprendan la relación jerárquica de la información.

1. Listas no ordenadas (<ul>)

Una lista no ordenada (unordered list) se utiliza cuando el orden de los elementos no altera su significado (p. ej. ingredientes para cocinar, características de un producto o enlaces de navegación).

Se define con la etiqueta contenedora <ul> y cada elemento individual se crea con <li> (list item). Los navegadores renderizan por defecto cada elemento precedido por un punto o viñeta.

Código HTML:
<ul>
    <li>HTML5 (Lenguaje de Marcas)</li>
    <li>CSS3 (Hojas de Estilo)</li>
    <li>JavaScript (Interactividad)</li>
</ul>
Resultado en el navegador:
  • HTML5 (Lenguaje de Marcas)
  • CSS3 (Hojas de Estilo)
  • JavaScript (Interactividad)
Listas en Menús de Navegación:

La inmensa mayoría de barras de navegación en la web (incluidas las de Bootstrap y los menús accesibles para lectores de pantalla) se construyen internamente como una lista <ul> dentro de un contenedor <nav>. Los estilos visuales (ocultar viñetas, colocar en horizontal o añadir espaciado) se aplican mediante CSS con list-style: none y display: flex.

Atributos obsoletos en <ul> (HTML5):

Antiguamente en HTML 4 se usaban type="disc|circle|square" y compact. En HTML5 ambos son obsoletos. Para personalizar o eliminar las viñetas, se debe emplear siempre la propiedad CSS list-style-type.

2. Listas ordenadas (<ol>) y sus atributos en HTML5

Una lista ordenada (ordered list) se emplea cuando el orden de los elementos es estrictamente relevante: pasos de una receta, procedimientos de instalación, clasificaciones o algoritmos paso a paso.

Atributos nativos y estándares de <ol> en HTML5:
Atributo Valores permitidos Significado y Utilidad en HTML5
type 1 (Decimal: 1, 2, 3...)
a (Minúsculas: a, b, c...)
A (Mayúsculas: A, B, C...)
i (Romanos minúsculas: i, ii, iii...)
I (Romanos mayúsculas: I, II, III...) 		Establece el sistema de numeración. Es plenamente estándar en HTML5 cuando el tipo de ordenación aporta significado legal o jerárquico al documento.
start Número entero (p. ej. start="5") Estándar en HTML5. Define el valor numérico inicial de la lista. Resulta imprescindible cuando una lista numerada se interrumpe con texto explicativo y continúa más abajo.
reversed Atributo booleano (presente o ausente) Novedad HTML5. Invierte la numeración en sentido descendente (p. ej. 3, 2, 1). Ideal para cuentas atrás o listas "Top 10".
value (en <li>) Número entero (p. ej. <li value="10">) Modifica de forma puntual el ordinal de un elemento concreto dentro de una lista ordenada, continuando la numeración sucesiva a partir de dicho valor.
Código con start y type:
<!-- Empieza en la letra D (4) con mayúsculas -->
<ol type="A" start="4">
    <li>Fase de Análisis</li>
    <li>Fase de Diseño</li>
    <li>Fase de Implementación</li>
</ol>
Resultado en el navegador:
  1. Fase de Análisis
  2. Fase de Diseño
  3. Fase de Implementación
Código con reversed (cuenta atrás):
<!-- Cuenta atrás automática en HTML5 -->
<ol reversed>
    <li>Lanzamiento del cohete</li>
    <li>Comprobación final de sistemas</li>
    <li>Encendido de motores principales</li>
</ol>
Resultado en el navegador:
  1. Lanzamiento del cohete
  2. Comprobación final de sistemas
  3. Encendido de motores principales

3. Listas anidadas (Jerarquías multinivel)

Para crear una sublista o lista jerárquica de varios niveles, es obligatorio seguir una regla sintáctica estricta:

Regla de oro: Una sublista (sea <ul> o <ol>) debe anidarse siempre DENTRO de una etiqueta <li> padre, antes de su etiqueta de cierre </li>. Colocar una sublista directamente entre dos <li> o como hija directa de otra lista es un error de validación HTML.
Estructura correcta:
<ul>
    <li>Módulo de Desarrollo Web
        <!-- Sublista DENTRO del <li> -->
        <ul>
            <li>HTML5 Semántico</li>
            <li>CSS3 y Bootstrap 5</li>
            <li>JavaScript ES6+</li>
        </ul>
    </li>
    <li>Módulo de Bases de Datos</li>
</ul>
Resultado en el navegador:
  • Módulo de Desarrollo Web
    • HTML5 Semántico
    • CSS3 y Bootstrap 5
    • JavaScript ES6+
  • Módulo de Bases de Datos

4. Listas de descripción (<dl>, <dt>, <dd>)

Conocidas en HTML 4 como "listas de definición", en HTML5 se denominan formalmente listas de descripción (description list). Se componen de:

  • <dl>: Elemento contenedor que agrupa los pares de términos y descripciones.
  • <dt> (description term): Término, nombre, concepto o clave.
  • <dd> (description details): Valor, definición, explicación o detalle asociado al término precedente.
Casos de uso habituales:
Glosarios de términos Palabras técnicas seguidas de su definición académica.
Fichas técnicas Asociaciones clave-valor como especificaciones de ordenadores (Procesador, RAM, GPU).
Preguntas frecuentes (FAQ) Donde <dt> representa la pregunta y <dd> la respuesta.
Código HTML:
<dl>
    <dt class="fw-bold text-primary">HTML5</dt>
    <dd>Lenguaje de marcas estándar para estructurar páginas web.</dd>
    
    <dt class="fw-bold text-primary">CSS3</dt>
    <dd>Lenguaje de hojas de estilo utilizado para el diseño y presentación visual.</dd>
    
    <dt class="fw-bold text-primary">Bootstrap 5</dt>
    <dd>Framework CSS responsivo basado en clases de utilidad y componentes modernos.</dd>
</dl>
Resultado en el navegador:
HTML5
Lenguaje de marcas estándar para estructurar páginas web.
CSS3
Lenguaje de hojas de estilo utilizado para el diseño y presentación visual.
Bootstrap 5
Framework CSS responsivo basado en clases de utilidad y componentes modernos.
Agrupación semántica con <div> en HTML5:

Una importante novedad de la especificación moderna es que está permitido envolver cada par <dt> / <dd> dentro de una etiqueta <div> directa dentro del <dl>. Esto facilita enormemente la maquetación en dos columnas o cuadrículas mediante CSS Flexbox o Grid sin romper la validez del documento.
