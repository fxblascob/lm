Módulo 1: HTML Semántica de Texto

03. Estructura del Texto y Flujo de Documento

El texto es el componente esencial de la Web. En HTML, el texto no se diseña arbitrariamente, sino que se dota de significado y estructura semántica para que navegadores, motores de búsqueda y lectores de pantalla lo comprendan y presenten adecuadamente.

1. Elementos de bloque frente a elementos de línea

Todos los elementos visuales de HTML pertenecen fundamentalmente a dos categorías de comportamiento en el flujo normal de la página:

Elementos de Bloque (Block)
  • Comienzan siempre en una nueva línea (salto de línea implícito antes y después).
  • Por defecto ocupan el 100% del ancho disponible en su contenedor padre.
  • Pueden contener elementos de línea y otros elementos de bloque.
  • Ejemplos: <p>, <h1>...<h6>, <div>, <header>, <nav>, <section>, <article>, <ul>, <li>.
Elementos de Línea (Inline)
  • Se posicionan uno tras otro en la misma línea de texto, adaptándose al flujo natural de lectura.
  • Solo ocupan el ancho estrictamente necesario para su contenido.
  • No inician un salto de línea y no deben contener elementos de bloque.
  • Ejemplos: <a>, <strong>, <em>, <span>, <code>, <img>.

2. El colapso de espacios en blanco (Whitespace Collapsing)

Si abres un editor de código y pulsas 5 veces la barra espaciadora o 3 veces la tecla Enter entre dos palabras, observarás que el navegador colapsa todo ese espacio en un único espacio simple: 

<p>Este         texto        tiene         muchos        espacios
y varios
saltos de
línea en el código.</p>

Resultado en el navegador:

Este texto tiene muchos espacios y varios saltos de línea en el código.

Este comportamiento es una ventaja: permite indentar y tabular el código fuente para que sea legible por programadores sin desconfigurar la apariencia final.

3. Párrafos con <p>

El párrafo es la unidad semántica básica de texto continuo. Se define con la etiqueta <p>...</p>. Cada párrafo crea automáticamente separación visual respecto al siguiente: 

<p>HTML5 ofrece elementos semánticos que dan sentido al contenido.</p>
<p>CSS se encarga de la estética visual, colores, espaciados y tipografía.</p>

HTML5 ofrece elementos semánticos que dan sentido al contenido.

CSS se encarga de la estética visual, colores, espaciados y tipografía.

4. Texto preformateado: <pre> y <code>

Cuando necesites mostrar texto exactamente tal y como está escrito en el archivo (respetando múltiples espacios, tabulaciones y saltos de línea sin colapso), se utiliza la etiqueta <pre>. Si además contiene código fuente, se combina con <code>: 

<pre><code>function saludar(nombre) {
    // Los espacios y sangrías se respetan exactamente
    console.log("Hola " + nombre);
}</code></pre>
function saludar(nombre) {
    // Los espacios y sangrías se respetan exactamente
    console.log("Hola " + nombre);
}

5. Saltos de línea forzados: <br>

La etiqueta <br> (break) introduce un salto de línea sin iniciar un nuevo párrafo.

Regla de oro: ¿Cuándo usar y cuándo NO usar <br>?

Uso correcto: En contenidos donde el salto de línea es intrínseco al texto y no representa un párrafo independiente, como estrofas poéticas o direcciones postales.
Uso incorrecto: Nunca utilices múltiples <br><br> para crear separación o margen entre elementos. El espaciado visual es competencia exclusiva de CSS (márgenes y paddings). 

<p>
    Calle Mayor, 12, 3º B<br>
    46002 Valencia<br>
    España
</p>

6. Jerarquía semántica de encabezados: <h1> a <h6>

Los encabezados (headings) estructuran la jerarquía lógica del documento en secciones y subsecciones. Hay 6 niveles disponibles, desde <h1> (máxima importancia) hasta <h6> (mínima importancia):

Encabezado de Nivel 1 (<h1>)

Encabezado de Nivel 2 (<h2>)

Encabezado de Nivel 3 (<h3>)

Encabezado de Nivel 4 (<h4>)

Encabezado de Nivel 5 (<h5>)
Encabezado de Nivel 6 (<h6>)
Buenas prácticas de accesibilidad y SEO con encabezados:
  • Un único <h1> principal por página: Debe resumir con precisión el tema global del documento.
  • No saltarse niveles en la jerarquía: No saltes de un <h1> directamente a un <h3>; desciende de forma ordenada (h1 → h2 → h3).
  • No usar encabezados para agrandar texto: Usa encabezados únicamente por su valor estructural. Si quieres texto más grande por motivos visuales, usa clases de CSS (ej. fs-1 o font-size), no etiquetas de encabezado.

7. Ruptura temática semántica: <hr>

Históricamente, la etiqueta <hr> (horizontal rule) se usaba como una línea divisoria decorativa. En la semántica moderna de HTML5, representa una ruptura temática entre párrafos (un cambio de escena en una narración, un cambio de tema o una transición en un artículo): 

<p>La expedición partió a primera hora de la mañana cruzando el valle.</p>

<!-- Ruptura temática: cambio temporal o de escena -->
<hr>

<p>Tres días más tarde, el campamento base divisaba la cumbre.</p>

La expedición partió a primera hora de la mañana cruzando el valle.

Tres días más tarde, el campamento base divisaba la cumbre.
