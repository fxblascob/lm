Módulo 1: HTML Navegación e Hipertexto

05. Hipervínculos y Navegación Web

El hipertexto es el pilar fundacional de la World Wide Web. Los hipervínculos permiten a los usuarios saltar de un documento a otro, navegar entre secciones internas, descargar recursos o comunicarse por correo electrónico y teléfono.

1. La etiqueta de ancla: <a>

Los enlaces se crean con el elemento <a> (Anchor) y su atributo obligatorio href (Hypertext Reference): 

<a href="https://www.w3.org">Visitar el sitio oficial del W3C</a>

En HTML5, el elemento <a> puede envolver no solo texto, sino también imágenes, listas completas o bloques enteros de contenido (tarjetas): 

<!-- Envolver una tarjeta o imagen completa en un enlace -->
<a href="perfil.html" class="text-decoration-none text-dark">
    <img src="avatar.jpg" alt="Foto de perfil">
    <h4>Juan Pérez</h4>
    <p>Ver perfil completo →</p>
</a>

2. Tipos de rutas web: Absolutas frente a Relativas

Rutas Absolutas (URLs Externas)

Apuntan a un recurso independiente en Internet. Incluyen siempre el protocolo seguro (https://), el dominio y la ruta completa:

<a href="https://developer.mozilla.org/es/">MDN Web Docs</a>
Rutas Relativas (Navegación Interna)

Apuntan a archivos dentro de nuestro propio sitio web tomando como referencia la posición del documento actual:

<a href="contacto.html">Misma carpeta</a><br> <a href="../index.html">Carpeta superior</a>
¡Error grave de principiante: Rutas locales de disco!

Nunca utilices rutas de disco local como C:\Users\alumno\pagina.html o file:///home/.... Esos enlaces solo funcionarán en tu ordenador personal y fallarán inmediatamente al subir la web a un servidor o a GitHub Pages. Usa siempre rutas relativas limpias.

3. El atributo target y seguridad con rel="noopener"

El atributo target define dónde debe abrirse el documento de destino:

  • target="_self" (Por defecto): Abre la página en la pestaña actual reemplazando la vista.
  • target="_blank": Abre el enlace en una nueva pestaña o ventana del navegador.
Seguridad web: Vulnerabilidad Reverse Tabnabbing

Al utilizar target="_blank" hacia páginas externas, la página abierta adquiere acceso al objeto window.opener de tu pestaña, pudiendo redirigir a tus usuarios a sitios fraudulentos de phishing.
Solución obligatoria: Añade siempre rel="noopener noreferrer":

<a href="https://sitioexterno.com" target="_blank" rel="noopener noreferrer">Enlace seguro</a>

4. Anclas internas y navegación por identificador (id)

Es habitual crear enlaces que salten a una sección específica dentro de una página extensa (como un índice de contenidos o un botón "Volver arriba"):

Paso 1: Identificar el destino con id

Asigna un atributo id único al encabezado o sección de destino: 

<h2 id="seccion-contacto">Contacto</h2>
Paso 2: Crear el enlace con almohadilla #

En el atributo href, escribe el carácter # seguido del ID: 

<a href="#seccion-contacto">Ir a Contacto</a>
Nota: El viejo <a name> está obsoleto

En HTML 4 era necesario escribir etiquetas vacías como <a name="ancla"></a>. En HTML5, cualquier elemento de la página (un <h2>, <section> o <article>) con un id es automáticamente un ancla accesible.

5. Protocolos especiales: Correo, Teléfono y Descarga forzada

El atributo href no solo acepta páginas web, sino también esquemas de protocolo de comunicación directa:

Protocolo / Atributo Ejemplo en código Comportamiento en el dispositivo
Correo (mailto:) <a href="mailto:info@ies.es">Escríbenos</a> Abre el cliente de correo predeterminado (Outlook, Gmail, Thunderbird) con el destinatario listo.
Teléfono (tel:) <a href="tel:+34960000000">Llamar al centro</a> En smartphones y tablets, abre directamente el marcador para realizar una llamada con un solo toque.
Descarga (download) <a href="guia.pdf" download="Guia_HTML.pdf">Bajar PDF</a> Fuerza la descarga inmediata del archivo en disco en lugar de abrirlo en el visor del navegador.

6. Accesibilidad en enlaces (Criterios WCAG)

Un enlace accesible debe tener un texto descriptivo y significativo por sí mismo:

  • Mala práctica: <p>Para ver nuestro horario, haz <a href="horarios.pdf">clic aquí</a>.</p> (Si un lector de pantalla lee solo la lista de enlaces, leerá "clic aquí", sin saber a qué conduce).
  • Buena práctica: <p>Consulta el <a href="horarios.pdf">horario escolar en PDF</a>.</p>
