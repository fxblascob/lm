16. Proyecto Final Integrador

Desarrollo de un sitio web completo integrando todos los contenidos del módulo: semántica HTML5, navegación, tablas, formularios interactivos, multimedia y validación W3C.

Índice HTML Descargar Enunciado PDF

1. Objetivo del Proyecto Integrador

El objetivo de este proyecto es diseñar y maquetar un sitio web multipágina completo sobre una temática libre o propuesta por el departamento (p. ej. portal escolar, tienda tecnológica, blog temático, empresa de servicios o asociación cultural), poniendo en práctica todos los estándares y buenas prácticas aprendidos a lo largo de las lecciones de HTML5.

Organización Limpia Estructura de carpetas normalizada con index.html raíz, subdirectorios para páginas secundarias, imágenes y documentos.
Semántica HTML5 Pura Uso riguroso de <header>, <nav>, <main>, <section>, <article>, <aside> y <footer> sin divitis.
Validación W3C Todas las páginas deben pasar la auditoría del Nu Html Checker del W3C con cero errores sintácticos.

2. Requisitos Técnicos Mínimos de Entrega

Bloque Técnico Requisito Específico
Cabecera y Metadatos Declaración <!DOCTYPE html>, <html lang="es">, <meta charset="UTF-8">, metaetiqueta viewport responsiva, título descriptivo en cada página y favicon vinculado.
Navegación e Hipervínculos Menú de navegación estructurado con <nav> y listas <ul>. Enlaces internos consistentes con rutas relativas, enlaces externos con target="_blank" rel="noopener noreferrer" y al menos un enlace ancla dentro de la página.
Imágenes y Recursos Imágenes con formatos optimizados (WebP, SVG, JPG, PNG). Atributo alt accesible en todas las imágenes y dimensiones declaradas (width y height). Al menos una imagen con pie explicativo usando <figure> y <figcaption>.
Datos Tabulares Al menos una tabla semántica con <caption>, <thead>, <tbody>, celdas de encabezado con scope="col|row" y combinación de celdas mediante colspan o rowspan.
Formulario Interactivo Un formulario completo con método POST, agrupado mediante <fieldset> y <legend>, con etiquetas <label for="...">, validaciones nativas de HTML5 (required, pattern) y tipos modernos (email, tel, date).
Multimedia Nativa Incrustación de un reproductor de vídeo o audio nativo con el atributo controls o un documento interactivo con <object> / <iframe>.
