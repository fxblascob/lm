Formularios

Introducción a los formularios

Los formularios se diseñaron para que el usuario pudiera enviar datos al servidor.

Un formulario HTML es una sección de un documento que contiene contenido normal, código, elementos especiales llamados controles y rótulos (labels) en esos controles. Los usuarios normalmente "completan" un formulario modificando sus controles (introduciendo texto, seleccionando objetos de un menú, etc.), antes de enviar el formulario a un agente para que lo procese (por ejemplo, a un servidor web o a un servidor de correo).

Al enviar un formulario, se envían como datos unas parejas de nombre-valor para cada control del formulario. Es por ello que cada control del formulario debe tener un nombre y almacenar un valor (que será modificable por el usuario).

Creación de formularios

La creación de un formulario se realiza escribiendo las etiquetas <form> </form>. Todos los contenidos del formulario (texto y controles) deberán incluirse entre dichas etiquetas. Un formulario puede contener texto y código HTML (párrafos, listas, etc.) además de los controles del formulario.

Los atributos que se deben indicar en la etiqueta <form> son los siguientes:

  • Atributo id. Indica el nombre de identificación que recibe el formulario. También se puede utilizar el atributo name, pero es menos recomendable.
  • Atributo action. Indica la URI del programa que manejará el formulario completado y enviado. Normalmente se indicará en este atributo la dirección web del servidor encargado de procesar el formulario. También es habitual mandar los datos por correo electrónico, en cuyo caso el atributo tendrá como valor lo siguiente: mailto:direccion_correo?subject=Asunto del mensaje.
  • Atributo method. Indica el método por el cual se enviarán los datos del usuario al servidor. Existen dos métodos: GET y POST. Se estudiará su significado en temas posteriores. Para los ejercicios utilizaremos POST.
  • Atributo enctype. Este atributo especifica el tipo de contenido usado para enviar el formulario al servidor (cuando el valor del atributo method sea post). El tipo más habitual que se suele indicar es "text/plain", aunque existen otros como "text/html", "image/png", "image/gif", "video/mpeg", "text/css", y "audio/basic". Cuando se quieran enviar archivos a través de formularios se debe usar el tipo "multipart/form-data"
  • Atributo accept-charset. Indica una codificación de caracteres que debe ser aceptada por el servidor para poder manejar este formulario.

El siguiente ejemplo muestra un formulario que va a ser enviado a una dirección de correo cuando sea enviado:

<form id="formulario1" action="mailto:correo@correo.es?subject=asunto" method="post" enctype="text/plain" accept-charset="utf-8">

   ...Contenido del formulario

</form>

Controles de los formularios

Todos los controles del formulario deberán llevar los siguientes atributos obligatoriamente:

  • Atributo name. Indica el nombre de control que recibe el control.
  • Atributo alt. Indica el texto que aparecerá si el navegador no muestra correctamente el control.
  • Atributo value. Indica el valor que almacena el control. En el caso de las cajas de texto, el contenido de este atributo será lo que escriba el usuario, por lo que no hará falta indicarlo; en el caso de una casilla de selección u otro control, sí que deberá indicarse en el código de la página, ya que en caso contrario no se enviaría ninguna información.

Además, cada control podrá incluir atributos específicos según qué tipo de control sea (ver la guía de referencia de HTML).

<Label>

Los <labels> deben indicar la función de cada campo, (nombre, adjuntar imagen, número de tarjeta de crédito...).

Un simple ejemplo de un label con el atributo for

<label for="name"> Púlsame </label>
<input type="text" id="name" name="nombre">

Aun mas simple

<label> Púlsame <input type="text" id="name" name="nombre""></label">

<input>

Inserta el elemento definido en "type" dentro del formulario.

Atributos

  • type: Indica el tipo de control de formulario: (text|pasword|checkbox|radio|submit|reset|file|hidden|image|button)
  • name: Nombre del control
  • size: Establece el ancho del control en pixels o en caracteres.
  • maxlength: Establece el nº máximo de caracteres para control de tipo texto o password.
  • checked: Marca la casilla para un control de tipo checckbox o radio
  • src: Indica la URI donde se encuentra la imagenn para type="image"
  • disabled: Este booleano desabilita el contro y no se puede introducir datos.
  • readonly: Este booleano immpide que el usuuario haga cambios en el control.
  • accept: Lista de tipos mime válidos para suubir ficheros.
  • placeholder: El atributo placeholder permite mostrar en los controles de texto un texto descriptivo que desaparece al escribir en él.
  • required (nuevo en HTML5) required que nos permite comprobar que el campo ha sido rellenado antes incluso de pulsar ese botón de envío, sin necesidad de más complicaciones o código extra.
  • value:
    • para cuadros de texto es el valor inicial que aparece en el recuadro.
    • para botones de tipo radio y checkbox es el valor que se envvía a servidor
    • para botones de acción es el título del botón.
  • pattern: obliga a que los datos de un campo tengan un patrón determinado
  • max, min: determina los límites inferior superior en campos con valores numéricos

Caja de texto

Se crea con la etiqueta y atributo <input type="text">.

Caja de texto cifrado

Se crea con la etiqueta y atributo <input type="password">.

Casilla de verificación

Se crean con la etiqueta y atributo <input type="checkbox">. Pueden activarse varias a la vez. Además, puede haber varias casillas de verificación con el mismo nombre de control, lo que permite que los usuarios indiquen varios valores para la misma propiedad.

Botones radio o radiobotones

Se crean con la etiqueta y atributo <input type="radio">. Los radiobotones que tengan el mismo nombre de control serán mutuamente exclusivos: sólo podrá activarse uno a la vez.

Botón de borrado

Se crea con la etiqueta y atributo <input type="reset">. Al pulsarlo, se borran todos los datos introducidos en el formulario. El atributo value almacena el texto que aparecerá sobre el botón.

Botón normal

Se crea con la etiqueta y atributo <input type="button">. La acción que se realizará cuando se pulse este botón se indica mediante un lenguaje de script que veremos en un tema posterior, por lo que ahora no nos será útil. El atributo value almacena el texto que aparecerá sobre el botón.

Botón de envío

Se crea con la etiqueta y atributo <input type="submit">. Al pulsarlo, se enviarán los datos introducidos en el formulario de acuerdo con lo indicado en el atributo action del formulario. El atributo value almacena el texto que aparecerá sobre el botón.

Control oculto

Se crea con la etiqueta y atributo <input type="hidden">. Se utiliza para mandar información no visible al usuario.

Su finalidad es la de enviar ciertos datos al servidor que no son útiles para el ciente. Por ejemplo: podemos enviar la fecha y hora junto con el resto de la información sin que el usuario lo perciba. Para obtener la fecha y hora sería necesario haccer un script que modifique el atributo vaue del control hidden.

Control de selección de archivo

Se crea con la etiqueta y atributo <input type="file">. Se utiliza para mandar archivos mediante el formulario. Si se usa, se debe indicar el tipo "multipart/form-data" en el atributo enctype del formulario.

Botón de imagen

Se crea con la etiqueta y atributo <input type="image"> Crea un botón de envío gráfico. Mediante el atributo src se debe indicar la URL de la imagen que debe mostrar el navegador en lugar del botón normal.

<button>

Sirve para insertar un botón como los creados por <input> pero con más posibilidades de formato, por ejemplo: incluir imágenes dentro del botón. Su atributo type indica el tipo de botón (submit|reset|button).

Ejemplo:

<button type="submit">
	<img width="60" height="40" src="../imagenes/marenostrum.jpg">
</button>

Caja de texto multilínea

Se crea con las etiquetas <textarea> </textarea>. El tamaño de la caja se indica mediante los atributos rows (número de líneas) y cols (número de caracteres por línea). El contenido inicial de la caja se indica entre las etiquetas de apertura y cierre.

Menú de selección

Se crea con las etiquetas <select> </select>. Cada opción ofrecida por el menú se representa por las etiquetas <option> </option>. Un elemento select debe contener al menos un elemento option.

A continuación se muestra el código de un menú de selección y el resultado obtenido:

<select name="elegir-componente">
   <option value="componente_1">componente_1</option>
   <option value="componente_2" selected>componente_2</option>
   <option value="componente_3">componente_3</option>
   <option value="componente_4">componente_4</option>
   <option value="componente_5">componente_5</option>
   <option value="componente_6">componente_6</option>
   <option value="componente_7">componente_7</option>
</select>

Se pueden crear menús de selección múltiple. Para ello se hace uso de los atributos size (para indicar el número de filas del menú que se ven al mismo tiempo) y multiple (para permitir una selección múltiple de opciones) de la etiqueta select:

<select name="elegir-componente" multiple size="4">
   <option value="componente_1">componente_1</option>
   <option value="componente_2" selected>componente_2</option>
   <option value="componente_3" selected>componente_3</option>
   <option value="componente_4">componente_4</option>
   <option value="componente_5">componente_5</option>
   <option value="componente_6">componente_6</option>
   <option value="componente_7">componente_7</option>
</select>

Consideraciones

El control de tipo text tiene el valor por defecto "user".

El control de tipo password sustituye los caracteres que introduce el usuario por simbolos para ocultarlos.

El control de tipo checkbox está marcado por defecto (atributo checked) puediendo ser desmarcado por el usuario.

El primer conjunto de botones tipo radio tienen el mismo name="genero", lo cual los hace mutuamente excluyentes.

El segundo conjunto de botones tipo radio tienen diferentes nombres por lo que es pisible seleccionar varios a la vez.

El control que contiene el descuento es readony por lo que el usuario no puede cambiar su valor.

El control de tipo file inserta un botón para realizar una búsqueda en el disco del fichero que se enviará con el formulario. Hay que definir el atributo enctype

El control de tipo submit envía los daatos del formulario a la URI especificada en el atributo action

El control de tipo reset recupera los valores por defecto de todos los controles.

El control de tipo button define un botón genérico para asociarle una determinada acción con un script, por ejemplo: cerrar la ventana del formulario.
