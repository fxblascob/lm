Marcos y marcos incrustados

Marcos incrustados ("inline frame", <iframe>)

Inserta un marco en línea dentro de un documento, es equivalente a insertar una página dentro de otra con el tamaño establecido.

El iframe es un objeto que se manipula con la misma libertad que cualquier otro elemento dentro del documento. Se suele utilizar para publicidad o sitios de colaboración

Atributos: name, src, frameborder, marginwidth, marginheight, scrolling, width, height

Sintaxis: 

<iframe src="URL">  </iframe>

Ejemplo: Visalización de la página "capas.html".

<iframe name="iframe_a" src="10_capas.html" width="800" height="200" 
  marginwidth="6" marginheight="4" frameborder="1" scrolling="auto"> 
</iframe>

Un iframe puede ser usado como marco "target" de un link. Para ello en el atributo del link se debe poner el atributo "name" del iframe

Así podríamos poner:

<p>
<a href="formularios.html" target="iframe_a">Cargar "formularios.html"</a>
<a href="capas.html" target="iframe_a">Cargar "Capas.html"</a>
</p>

Pulsa sobre el siguiente enlace: Cargar "formularios.html"

Para volver a cargar la página de antes: Cargar "Capas.html"

Ejemplo de uso para ver un vídeo

<iframe width="560" height="315" src="https://www.youtube.com/embed/dTA9Yd0ODiE" 
	        frameborder="0" allowfullscreen>
</iframe>
