09. Marcos en la Web: El elemento <iframe>

Incrustación de contextos de navegación independientes con <iframe>, erradicación de <frameset>, accesibilidad con title, aislamiento seguro con sandbox y diseño adaptativo con Bootstrap.

Índice HTML Ejercicios

1. Evolución histórica: La desaparición de <frameset>

En las décadas de 1990 y principios de 2000 (HTML 4.01), existían dos formas de trabajar con marcos:

  1. Conjuntos de marcos (<frameset>, <frame>, <noframes>): Dividían la ventana completa del navegador en paneles estáticos independientes sustituyendo al elemento <body>.
  2. Marcos en línea (<iframe> - inline frames): Permiten incrustar un documento web secundario dentro del flujo normal de una página con su propio <body>.
Erradicación total de <frameset> en HTML5:

La especificación moderna de HTML5 eliminó por completo los elementos <frameset> y <frame>. Se consideraron una de las peores tecnologías de la historia web debido a que:

  • Rompían el historial del navegador: El botón "Atrás" dejaba de funcionar de forma lógica.
  • Impedían guardar en favoritos o compartir URLs: La barra de direcciones siempre mostraba la página marco raíz, ocultando la URL del contenido real.
  • Destruían el SEO: Los motores de búsqueda indexaban páginas sueltas sin su menú de navegación.
  • Graves problemas de accesibilidad: Para lectores de pantalla suponía una navegación caótica e incomprensible.

En la web moderna, el único estándar admitido es el marco en línea: <iframe>.

2. Sintaxis básica y atributos esenciales de <iframe>

Un <iframe> crea un contexto de navegación anidado (nested browsing context). Es decir, renderiza un documento HTML completo independiente dentro del documento padre.

Sintaxis moderna recomendada en HTML5:
<iframe src="https://www.openstreetmap.org/export/embed.html?..." 
        title="Ubicación geográfica del centro educativo" 
        width="600" 
        height="400" 
        loading="lazy">
</iframe>
Atributo Valor / Tipo Propósito y Buenas Prácticas Modernas
src URL relativa o absoluta Ruta o dirección web de la página o recurso externo que se desea incrustar.
title Texto descriptivo Obligatorio para accesibilidad (WCAG). Describe el contenido del marco para que los usuarios con lectores de pantalla sepan qué contiene sin necesidad de interactuar con él.
width / height Entero en píxeles Dimensiones fijas del marco. En HTML5 no llevan 'px' ni '%'; el diseño adaptable se controla con CSS.
loading lazy | eager Optimización de rendimiento (Core Web Vitals). loading="lazy" pospone la carga de mapas o vídeos pesados hasta que el usuario hace scroll hacia ellos.
name Identificador de texto Asigna un nombre al marco para actuar como destino de enlaces con el atributo target (p. ej. <a target="mi_marco">).
frameborder, scrolling, marginwidth, marginheight Valores obsoletos Obsoletos en HTML5. Para quitar bordes o ajustar barras de scroll se debe utilizar CSS con border: 0; o overflow: hidden;.

3. Ciberseguridad web: El atributo sandbox

Incrustar páginas de sitios web de terceros en tu propia web entraña importantes riesgos de seguridad (robo de cookies, ejecución de scripts maliciosos XSS, apertura de ventanas emergentes o redirección de tu sitio a una web fraudulenta).

Para solucionar esto, HTML5 introdujo el atributo sandbox, que crea una caja de arena de seguridad de máximo aislamiento.

Modo Restrictivo Máximo: <iframe sandbox>

Si se añade sandbox sin ningún valor adicional, se bloquea absolutamente todo:

  • Desactiva la ejecución de JavaScript.
  • Impide enviar formularios.
  • Bloquea pop-ups o nuevas pestañas.
  • Impide el acceso a cookies, LocalStorage o SessionStorage del navegador.
  • Impide que el iframe redireccione la página principal.
Permisos Selectivos Controlados

Podemos otorgar permisos específicos separándolos por espacios:

  • allow-scripts: Permite ejecutar JavaScript dentro del marco.
  • allow-same-origin: Permite al contenido mantener su origen original.
  • allow-forms: Permite enviar formularios dentro del marco.
  • allow-popups: Permite abrir enlaces con target="_blank".
  • allow-modals: Permite abrir diálogos modales (como window.alert).
Ejemplo de incrustación segura:
<!-- Permite scripts y formularios pero bloquea acceso a almacenamiento y redirecciones -->
<iframe src="https://widget-externo.com/formulario" 
        title="Formulario de encuesta externa"
        sandbox="allow-scripts allow-forms">
</iframe>

4. Casos de uso contemporáneos de <iframe>

A. Incrustación de vídeos de plataformas (YouTube / Vimeo)

Para reproducir un vídeo de YouTube se utiliza la URL en formato embed junto con la política de permisos allow y allowfullscreen: 

<iframe width="560" 
        height="315" 
        src="https://www.youtube.com/embed/dTA9Yd0ODiE" 
        title="Tutorial de LMSGI en YouTube" 
        allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" 
        allowfullscreen>
</iframe>
B. Incrustación de mapas interactivos (OpenStreetMap / Google Maps)

Permite añadir un mapa navegable y táctil en páginas de contacto sin necesidad de programación JavaScript compleja: 

<iframe width="100%" 
        height="300" 
        src="https://www.openstreetmap.org/export/embed.html?bbox=-0.525%2C38.395%2C-0.515%2C38.405&layer=mapnik" 
        title="Ubicación en OpenStreetMap"
        loading="lazy">
</iframe>
C. Enlaces que cargan contenido dentro de un <iframe>

Mediante el atributo name del iframe y el atributo target de una etiqueta <a>, podemos hacer que al hacer clic en un enlace su destino se abra dentro del marco sin recargar la página entera:

Código del visor con target:
<!-- Enlaces con target dirigido al nombre del marco -->
<div class="btn-group mb-3">
    <a href="./10_capas.html" target="visor_temario" class="btn btn-sm btn-outline-primary">
        Ver Lección 10 (Capas)
    </a>
    <a href="./11_formularios.html" target="visor_temario" class="btn btn-sm btn-outline-primary">
        Ver Lección 11 (Formularios)
    </a>
</div>

<!-- Marco receptor con el atributo name correspondiente -->
<iframe name="visor_temario" 
        src="./10_capas.html" 
        title="Visor interactivo de temas" 
        width="100%" 
        height="280" 
        class="border rounded shadow-sm">
</iframe>

5. Marcos adaptativos para móviles (Bootstrap 5 Ratio)

Uno de los fallos más habituales al insertar vídeos o mapas con <iframe> es definir un ancho fijo como width="560". En teléfonos móviles con pantallas de 360px a 400px de ancho, el marco desborda la pantalla horizontalmente.

La solución moderna en Bootstrap 5 es envolver el <iframe> en un contenedor con la clase .ratio y la proporción deseada (p. ej. .ratio-16x9, .ratio-4x3 o .ratio-21x9): 

<!-- Contenedor responsivo 16:9 automático -->
<div class="ratio ratio-16x9 rounded-4 shadow-sm overflow-hidden">
    <iframe src="https://www.youtube.com/embed/dTA9Yd0ODiE" 
            title="Vídeo demostrativo del temario" 
            allowfullscreen>
    </iframe>
</div>
Simulación adaptable 16:9

Gracias a la clase .ratio, el reproductor de vídeo o mapa mantendrá siempre su proporción perfecta tanto en un monitor panorámico de sobremesa como en la pantalla vertical de cualquier smartphone.
