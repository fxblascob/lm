01. Organización de un sitio web

Esquema y distribución de directorios recomendados para organizar páginas HTML, hojas de estilo CSS e imágenes.

Índice HTML Ejercicios

Estructura recomendada de carpetas

Un sitio web rara vez está compuesto por una única página. Habitualmente se organiza en múltiples páginas HTML interconectadas mediante hipervínculos, acompañadas de recursos estáticos complementarios (imágenes, hojas de estilo CSS, scripts JavaScript, vídeos y documentos descargables).

Para facilitar el mantenimiento, la claridad de las rutas relativas y la escalabilidad del proyecto, se emplea una estructura modular de carpetas:

Figura 1.1: Esquema jerárquico estándar para proyectos web en el aula.

Regla de entrega para el curso

Todas las prácticas y proyectos del módulo deberán ajustarse estrictamente a este esquema de carpetas para garantizar que los enlaces relativos funcionen tanto en local como en los servidores de evaluación y en GitHub Pages.
