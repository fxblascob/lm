Acerca de este tutorial

Este tutorial pretende servir como guía de iniciación para todos aquellos que quieran acercarse al Hypertext Preprocessor (PHP). Por ello se recorren los aspectos básicos de la sintaxis de éste lenguaje, así como sus principales funciones.
