Este tutorial está  pensado como herramienta tanto para el aprendizaje de la creación de páginas HTML para usuarios novatos en este campo, como para consulta y ampliación de conocimientos de usuarios más experimentados. Consta de varios apartados, cuyo contenido se detalla a continuación:
  • Conceptos básicos:
    Este apartado pretende, a modo de introducción, aclarar los conceptos básicos sobre HTML, Web, clientes, servidores y direcciones URL.

  • Guía rápida:
    Esta guía no es exhaustiva, ni mucho menos. Está pensada como introducción al HTML, explicando de forma escueta los elementos más importantes para, en poco tiempo, tener los conocimientos generales necesarios para poder crear una página Web sencilla. Los elementos aquí explicados corresponden al HTML 2.

  • Guía detallada:
    Esta guía entra más en detalle en cada uno de los elementos y las posibilidades que ofrece el lenguaje HTML. Trata, básicamente, los elementos pertenecientes al HTML 2, aunque en algunos apartados se detallan elementos del Netscape y del HTML 3. Normalmente incluye numerosos ejemplos en cada uno de sus apartados. Está pensado tanto para la iniciación de usuarios a este lenguaje como para la ampliación de conocimientos y consulta por parte de usuarios que ya lo conocen.

  • Interfaz con el exterior:
    El HTML es un lenguaje que crea páginas estáticas. Aquí, por tanto, se trata de explicar la idea de que para realizar una página dinámica, interactiva con el usuario, será necesario apoyarse en la programación de scripts CGI (Common Gateway Interface). Estos no serán explicados en este tutorial, pero se incluyen direcciones Web donde poder encontrar la información oportuna sobre este tema.

  • Herramientas:
    Existen numerosas herramientas de apoyo para la realización de páginas Web. En este apartado se indican numerosas direcciones Web donde poder encontrar información sobre dichas herramientas. Mediante estas direcciones se podrán obtener diversas herramientas freeware y shareware.

  • Glosario:
    Aquí se incluye una amplia lista de elementos de las distintas versiones del HTML, Netscape, IExplore, Mosaic,... Para cada uno de ellos se incluye una breve explicación indicando los atributos que poseen y los valores que dichos atributos pueden tomar.

  • Bibliografía:
    En este apartado se incluyen referencias a diversas direcciones Web que contienen información sobre algún tema relacionado con HTML, así como las referencias de algunos libros de consulta.
