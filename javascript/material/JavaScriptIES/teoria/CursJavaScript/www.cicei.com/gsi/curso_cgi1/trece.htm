LOS PANELES



Consiste en dividir la ventana del browser en varias zonas, denominadas paneles. Cada una de estas zonas es capaz de mostrar código HTML, como es el caso de las celdas de una tabla. Sin embargo, existe una gran diferencia y es que en el caso de una tabla, todas las celdas forman parte del mismo documento HTML. Y en el caso de los frames, cada zona de la pantalla es un documento HTML propio. Se ve pues simultáneamente, en la misma ventana de un browser, la paginación correspondiente a varios ficheros HTML diferentes.

En un documento clásico, el cuerpo se inserta en las marcas <BODY>...<BODY>. En el caso de los paneles, el cuerpo del documento se inserta sistemáticamente en las marcas <FRAMESET>...</FRAMESET>, y además sólo puede componerse a partir de las tres nuevas marcas <FRAMESET>,<FRAME> y <NOFRAMES>.

<FRAMESET>

Es la marca de apertura que permite dividir una zona en subzonas, bien verticalmente, bien horizontalmente. Si no hay ninguna zona definida todavía, las divisiones se aplican a la zona inicial formada por el conjunto de la ventana del browser. Esta marca posee dos atributos:
ROWS se utiliza para dividir la zona en subzonas horizontales.
La sintaxis es:
ROWS="altura_zona_1, altura_zona_2,..., altura_zona_n"
Es una lista de valores enteros separados por comas. Cada uno de los valores de la lista puede darse según uno de los tre formatos siguientes, donde n es un entero:
n: el valor de n indica la altura de la subzona en número de pixels;
n%: n indica la altura de la subzona expresada en porcentaje del tamaño de la zona madre;
n*: aquí, n es opcional. El carácter * indica al browser que debe dar a la subzona todo el espacio aún disponible. Cuando varios elementos de la lista utilizan este formato, el espacio aún disponible se reparte entre las subzonas correspondientes. n podrá entonces utilizarse para indicar al browser que una subzona deba recibir una proporción n veces superior del espacio aún disponible.
COLS se utiliza para dividir la zona en subzonas verticales.
La sintaxis es idéntica a la del atributo ROWS:
COLS="anchura_zona_1, anchura_zona_2,..., anchura_zona_n"

<FRAME>

Es la marca utilizada para caracterizar las subzonas definidas mediante la marca <FRAMESET>. Posee seis atributos:
SRC indica el URL del documento que debe mostradse en esta zona. Si este atributo no se indica, entonces la zona está vacía.
La sintaxis es:
SRC="url"
NAME se utiliza para nombrar la zona a fin de que pueda convertirse en el destino de cualquier enlace de hipertexto.
Sintaxis:
NAME="nombre_de_la_zona"
MARGINWIDTH se utiliza para precisar el número de pixels entre los bordes izquierdo y derecho de la zona y el documento HTML a visualizar.
Sintaxis:
MARGINWIDTH="n"
MARGINHEIGHT se utiliza para precisar el número de pixels entre los bordes superior e inferior de la zona y el documento HTML a visualizar.
Sintaxis:
MARGINHEIGHT="n"
SCROLLING indica si la zona debe poseer una barra de desplazamiento (SCROLLING="yes"), si no debe contar con ella (SCROLLING="no") o si esta elección se deja en manos del browser (SCROLLING="auto").
Sintaxis:
SCROLLING="yes/no/auto"
NORESIZE no tiene un valor. Su presencia indica únicamente al browser que debe impedir toda modificación del tamaño de una zona. Cuando este atributo no se precisa, es posible deformar una zona desplazando su frontera mediante el ratón.

<NOFRAMES>

Es una marca que indica a todo browser incapaz de gestionar los frames el texto que debe presentar al usuario en lugar de los paneles. Este texto lo ignoran los browsers capaces de gestionar los paneles.
Finalmente, se ha creado un nuevo atributo, denominado TARGET, para poder indicar en qué panel debe mostrarse el documento asociado a un enlace de hipertexto. Afecta a las marcas que caracterizan los enlaces de hipertexto, en particular las marcas <A> y <FORM>. Consideremos por ejemplo el enlace de hipertexto siguiente:
<A HREF="/dossier.html" TARGET="zonadossier">Ver el dossier</A>
El atributo TARGET existe para indicar al browser que en respuesta a un clic, debe mostrar el documento dossier.html en el panel cuyo nombre es "zonadossier" (es decir, el panel que ha sido definido por la marca <frame NAME="zonadossier"...>). De igual modo, la sumisión del formulario definido por :
<FORM ACTION="cgi-bin/test" TARGET="zonascript" METHOD=POST>
...
</FORM>
mostrará sus resultados en el panel cuyo nombre es <<zonascript>>.

Tres casos para describir los valores posibles del atributo TARGET:

  • TARGET tiene un valor que corresponde al nombre de un panel existente. El documento asociado al enlace de hipertexto se muestra entonces en el panel en cuestión.
  • TARGET tiene un valor que no corresponde a ninguno de los paneles existentes. El browser crea entonces una nueva ventana (un nuevo browser) y muestra el documento. ;Esta nueva ventana se considera como un panel con el nombre del atributo TARGET del origen de su creación.
  • Finalmente, TARGET toma uno de los cuatro valores predefinidos siguientes:
    • _blank, que se utiliza para indicar al browser que debe crear una nueva ventana (es decir, un nuevo browser) con el fin de mostrar el documento. El nuevo browser es un panel que no tiene nombre y no puede ser por tanto el destinatario de otro enlace de hipertexto;
    • _self, que indica que el documento se cargará en la misma zona donde se encuentra el enlace de hipertexto. Se trata del valor predeterminado cuando no se indica el atributo TARGET;
    • _top, que indica al browser que suprima todos los paneles existentes y visualice el documento de modo normal ocupando toda la superficie del browser;
    • _parent, que indica al browser que visualice el documento ocupando toda la superficie de la zona en la que se ha visualizado el documento que contiene el enlace;
