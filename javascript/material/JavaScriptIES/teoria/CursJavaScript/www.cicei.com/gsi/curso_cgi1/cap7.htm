ESTILOS

Los estilos de presentación de textos no permiten escoger un tipo de letra particular con un tamaño preciso. Es el browser quién decidirá la presentación en función de sus posibilidades y de la parametrización hecha por el lector.

Los elementos de estilo permitirán atribuir a palabras o párrafos atributos predefinidos. HTML define dos métodos para la presentación de caracteres: el estilo físico y el estilo lógico.

ESTILO FÍSICO:

Las marcas siguientes indicarán explícitamente el tipo de caracteres a utilizar.
  • <B> .... </B>
    Esta marca indica un texto en negrita.

  • <I> .... </I>
    Esta marca señala un texto en cursiva

  • <U> .... </U>
    Esta marca indica un texto subrayado (no es reconocida por todos los browsers).

  • <TT> .... </TT>
    Es una marca para poner el texto en caracteres de tipo máqina de escribir (teletipo). La fuente utilizada es de tipo no proporcional.

ESTILO LÓGICO:

Los ocho estilos lógicos definidos en HTML no producirán forzosamente otras tantas representaciones diferentes.
  • <CITE> .... </CITE>
    Esta marca se usa a menudo para citar una obra o una referencia (para una cita se utilizará la marca <BLOCKQUOTE>). Normalmente el browser utilizará caracteres en cursiva para este exto.

  • <CODE> .... </CODE>
    Se utiliza para un ejemplo de programa informático; se seleccionarán caracteres de tipo máquina de escribir con fuente no proporcional.

  • <DFN> .... </DFN>
    Se utiliza para la definición de un término. Su representación dependerñá del browser.

  • <EM> .... </EM>
    Permite el resaltado de un texto; normalmente se utilizarán caracteres en cursica.

  • <KBD> .... </KBD>
    Sirve para ilustrar una entrada por teclado; se seleccionarán caracteres tipo máquina de escribir con fuente no proporcional.

  • <SAMP> .... </SAMP>
    Se utiliza para un ejemplo de texto; generalmente se utilizarán caracteres tipo máquina de escribir con fuente no proporcional.

  • <STRONG> .... </STRONG>
    Esta marca se utiliza para resaltar (en negrita) un texto.

  • <VAR> .... </VAR>
    Se usa para representar una variable en un contexto informático (se utiliza cursiva).

  • <BLOCKQUOTE> .... </BLOCKQUOTE>
    Se utilizan caracteres estándar, el bloque de texto será desplazado hacia la derecha y se generarán espacios de tipo párrafo antes y después del bloque. Puede utilizarse en la misma línea que la marca <CITE>.

EXTENSIÓN NETSCAPE

NETSCAPE propone una extensión a HTML 2 permitiendo regular el tamaño y color de los caracteres mediante una marca especial:

<FONT SIZE=tamaño COLOR=#rrggbb>

Esta marca permite actuar sobre bloques distintos de caracteres situados en una misma línea.

El atributo SIZE permite regular el tamaño de los caracteres mediante una escala relativa entre 1 y 7.

El atributo COLOR especifica el color de los caracteres. Se utiliza el modelo RGB, que define el color siguiendo la estructura #rrggbb, donde rr, gg, bb son valores hexadecimales comprendidos entre 00 y FF que especifican el grado de saturación de los colores rojo, verde y azul. Por ejemplo, FF0000 da un rojo con intesidad máxima, FFFFFF da blanco, 000000 negro, etc.
