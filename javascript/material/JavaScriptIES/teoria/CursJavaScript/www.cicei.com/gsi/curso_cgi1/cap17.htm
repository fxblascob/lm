FORMULARIOS Y CGI


La programación CGI aplicada a los formularios se diferencia de la programación
clásica en que el cliente debe enviar el conjunto de los datos entrados por el
usuario. Para ello, el cliente construye una cadena de caracteres que contiene un
conjunto de parejas (nombre de campo, valor entrado).
Esta cadena posee el siguiente formato:

nombre_campo1=valor1&nombre_campo2=valor2&...

Los espacios se reemplazan por '+' y los caracteres esenciales por su valor
hexadecimal bajo el formato %xx.

Una vez construída la cadena se envía al servidor según el método indicado en el
atributo METHOD de la marca <FORM>.

METODO GET

En este método, la cadena de caracteres se añade al URL que referencia el script a
ejecutar. La separación entre el nombre del script y la cadena se realiza mediante
el carácter '?'. En la ejecución del script cgi, esta cadena encontrará en la variable de entorno QUERY_STRING.

METODO POST

Es el método más utilizado para el tratamiento de formularios. La cadena de caracteres no se añade al URL sino se envía mediante una secuencia HTTP especial. Antes de ejecutar el script cgi, el servidor posiciona la variable de entorno CONTENT_LENGTH para indicar la longitud de la cadena que ha recibido. Entonces, ejecuta el script enviando la cadena a la entrada est´ndar del script. Para recuperar la cadena de datos, el script debe leer CONTENT_LENGTH caracteres de su entrada estándar.

La Programación

El primer trabajo de un script cgi destinado a gestionar un formulario consistirá en recuperar la cadena de caracteres que contiene los datos, decodificarla y finalmente extraer los pares (nombre del campo, valor entrante) En la práctica los scripts se diseñan de modo que puedan dar respuesta a ambos métodos (GET y POST). Para realizar el trabajo repetitivo de decodificación y extracción es aconsejable utilizar las siguientes:

  • cgi-lbi.pl para PERL
  • libcgi para el C
