ESTRUCTURA BÁSICA

MARCAS

HTML es un lenguaje de marcas en el que cada marca se inscribe entre los caracteres < y >. Un texto marcado tendrá el siguiente aspecto:

        ... texto normal 
        <marca> 
                texto afectado por la marca 
        </ marca>
        resto del texto ...



SÍMBOLOS Y ACENTUACIÓN

Es necesario utilizar palabras clave en el documento para los caracteres acentuados y otros símbolos. Por ejemplo, si se quiere utilizar los caracteres < > en el texto normal, debemos reemplazarlos por &gt para el carácter > y por &lt para el carácter <.

ESTRUCTURACIÓN DE UN DOCUMENTO HTML

  • <HTML> .... </HTML>
    Todos los documentos HTML deben estar enmarcados por estos elementos.
  • <HEAD> .... </HEAD>
    Zona de prólogo o de encabezamiento. Dentro de esta zona se pueden situar las siguientes marcas:
    • <TITLE> .... </TITLE> : El texto situado entre estas dos marcas aparecerá en la zona de título del browser.
    • <BASE HREF="URL"> : Indica la dirección base de todo URL incompleto en el documento.
    • <ISINDEX ... > : Permite una búsqueda por palabra clave del documento.
    • <LINK HREF="URL"> : Indica relaciones entre documentos. Generalmente se usa para indicar el autor, índices y glosarios, otras versiones , etc.
    • <NEXTID ... > : Crea un identificador único del documento.
    • <META> : Especifica información del documento no definida por otras marcas HTML. Esta información puede ser extraida por Cliente/Servidor para su uso.
  • <BODY> .... </BODY>
    En esta zona reside el resto del documento.
  • <ADDRESS> .... </ADDRESS>
    Contiene la información respecto al autor del documento. Puede insertarse en cualquier lugar del documento; aunque lo habitual es colocarlo al final del mismo.
  • <!--Comentario -->
    Todo texto que empieze por <!-- y termine con --> es ignorado por el browser, por lo que no será visible. De esta forma se pueden incluir comentarios en el fichero fuente.


En conclusión, podemos decir que la estructura básica de un documento HTML es: 

<HTML> 
   <!-- Esqueleto HTML -->
   <HEAD> 
      <TITLE> Emplazamiento del título </TITLE>
   </HEAD>
   <BODY>
      Documento
      ... 
      <ADDRESS> 
         Nombre del autor - Dirección e-mail
      </ADDRESS>
   </BODY>
</HTML>

(Aunque esto sería lo correcto, no te sorprendas si encuentras documentos HTML que no utilizan exactamente esta estructura)
