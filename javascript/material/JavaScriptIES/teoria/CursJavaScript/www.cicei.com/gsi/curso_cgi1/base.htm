Acceso a un servidor de Base de Datos

¿Por qué usar el WWW?

  • Interfase Gráfica para Usuario (GUI):

    Esta interfase hace los accesos a la base de datos más fácil pero la implementación de tal interfase requiere que el usuario sea un programador habilidadoso. Los Web browser proveen un GUI que puede ser usado para acceder a muchas cosas, entre ellas a bases de datos. Usando los formularios incorporados del browser, los usuarios pueden acceder a una base de dato simplemente rellenando los datos y presionando un botón.

  • Estandarización:

    Los web browsers acceden a documentos en máquinas de todo el mundo. Estos documentos están hechos en HTML. Un documento HTML puede ser leído por usuarios de cualquier máquina en el mundo. Así usando un conjunto standard de herramientas, el mantenimiento del código se simplifica y la implementación de nuevas ideas se hace más rapidamente.

  • Soporte de una plataforma cruzada:

    Los browsers
    • están disponibles para casi todas las máquinas. Los browsers y HTML proveen medios de acceso al WWW desde muchos diferentes tipos de máquinas. Este soporte permite a los usuarios en la mayoría de los diferentes tipos de máquina

  • Acceso a la red:

    Uno de los beneficios de tener un servidor HTTP, es que el ruido de red es manejado por el cliente y el servidor HTTP con lo cual ni el usuario ni el programador de HTML necesitan saber nada de la red. Esto simplifica la tarea de acceso a base de datos ya que se elimina el problema de tener dos plataformas diferentes de hardware.

Acceso a una base de Datos

  • CGI (Common Gateway Interface )

     Los servidoreds HTTP proporcionan un método para ejecutar programas externos desde dentro de un documento HTML. Este método se denomina CG. El servidor le pasa información al programa CGI y obtiene los resultados de la ejecución. Este método permite al usuario pasar información al programa CGI mediante un formulario. El programa procesa información y retorna el resultado en formato HTML o en texto. CGI se presta mucho a la tarea de coger información de una base de datos. La flexibilidad del CGI permite el uso de cualquier método de acceso, e incluso permite el uso de múltiples bases de datos en múltiples servidores.

  • Tipos de Interfase:

    Los programas CGI pueden pueden ser de casi cualquier tipo: sed,awk,perl,shell scripts.... Los programas CGI sólo necesitan leer datos de la entrada, o acceder a las variables de entorno para los datos. Una vez que los datos sean leídos se generan los resultados o bien en foemato HTML o bien en texto ASCII. La mayoría de los programadores han emigrado al Perl. Las habilidades de procesamiento de texto del Perl y su versatilidad así como su soporte de plataforma cruzada le hacen ser la mejor elección para los scripts CGI.
    Una instrucción de SQL puede ser pasada en piezas y el programa CGI une las piezas, pasando la instrucción a la base de datos, obtener los resultados, formatearlos y pasarlos al servidor HTTP.

Métodos de Acceso

Existen diferentes métodos de acceder a una base de datos desde un web browser. Algunas bases de datos tienen su propio software de interfase con la red, otras requieren un producto adicional y otras no tienen ninguno. Todos estos métodos usan el procedimiento HTTP CGI gateway. Para que un servidor HTTP pueda ejecutar programas CGI, debe estar configurado para permitir el acceso CGI. A la hora de configurar el servidor HTTP, la seguridad debe ser tenida en cuenta.

  • Base de Datos con sofware interno de red:

    Si el cente HTTP y el servidor de la base de datos están en diferentes m´quinas, el software de red de la base de datos es instalado en la misma máquina del cliente HTTP. Si los dos están en la misma máquina, algún tipo de software de acceso será proporcionado por la propia base de datos.

  • Base de Datos sin Software interno de red

    El cliente HTTP y el servidor pueden estar en diferentes máquinas pero el servidor HTTP y el servidor de la Base de Datos deben estar en la misma máquina. La red que haya entre las dos máquinas puede ser una red Novell entre los PC's o una red TCP/IP en UNIX... El servidor HTTP debe estar configurado para permitir acceso CGI.

  • Usando software de red externo

    Esta solución es sólo para usuarios accediendo al servidor DB desde una máquina remota. No hay necesidad de software de red en la máquina local. El software del servidor de red debe de aceptar una query de la base de datos, transportarla a través de la red, entreg´rsela al servidor de base de datos, obtener los resultados, llevar los resultados a través de toda la red y entregárselos al software de la pasarela para que se los entreguen al cliente HTTP. El servidor de red en la máquina del servidor de la base de datos puede hacer llamadas directas a la base de datos a través de un API proporcionado por la base de datos, o a través de alg´n otro software de acceso a base de datos.
