IMÁGENES MAPEADAS


La correspondencia entre diferentes zonas de una imagen y diferentes URL se denomina imagen mapeada o también imagen reactiva. Para realizar una imagen activable, se empezará por poner la imagen con el tamaño deseado. Después de determinar el tamaño óptimo, se hará una lista de coordenadas zona por zona de las superficies activables. Si se decidiera posteriormente modificar el tamaño de la imagen, todo este trabajo tendría que repetirse. Las zonas activables podrán tomar las formas de rectángulo, círculo o polígono.

Una imagen se mide en puntos o pixels y el origen de estas coordenadas se sitúa arriba y a la izquierda de la imagen.
Para la realización del mapa de coordenadas - URL se creará un fichero en el que cada línea definirá una forma geométrica para la zona activable y su URL asociado.
Sintaxis:

forma URL coordenada X, coordenada Y coordenada X, coordenada Y ...,...
El número de puntos dependerá de la forma de la zona:
  • RECT, se utiliza para un rectángulo definido por dos puntos: el extremo superior izquierdo y el extremo inferior derecho.
  • CIRCLE, se utiliza para un círculo definido por dos puntos: el centro y un punto cualquiera situado sobre la circunferencia.
  • POLY, se utiliza para un polígono definido por un máximo de 100 vectores: se da la dirección de cada extremo del vector.

Una imagen mapeada se define por el siguiente conjunto de marcas:

<A HREF=/cgi-bin/imagemap/nombre simbólico >
<IMG SRC=url_del_fichero.gif ISMAP>
</A>
/cgi-bin/imagemap/ es un programa que debe estar instalado previamente en el servidor Web para poder proponer imágenes mapeadas.

imagemap.conf es un fichero instalado en la raíz del servidor en el que se referenciará con un nombre_simbólico la dirección real del fichero en el que se describen las relaciones entre las zonas activables y sus URL asociados.

A petición del browser el servidor envía la imagen mapeada. El lector hace clic sobre una zona de la imagen; gracias al atributo ISMAP, elbrowser recupera las coordenadas de la imagen, seguidamente desencadena el acceso al URL cgi-bin/imagemap pasando los parámetros siguientes: el nombre simbólico del fichero xxx.map y las coordenadas X e Y del punto activado. El programa imagemap abre el fichero imagemap.conf y recupera la dirección real del fichero xxx.map que abrirá. Compara la pareja X,Y con las diferentes zonas definidas en este fichero y detecta así el URL solicitado. Entonces efectúa la conexión con este URL.

HTML3 permite la realización de mapas activables en los que sólo interviene el cliente. Es mucho más fácil con este nivel de HTML, porque todo está descrito en el mismo fichero y ya no se necesita un programa exterior (cgi-bin).

En el primer caso (ISMAP), el servidor es quien se encarga de detectar a partir de las coordenadas del punto activado el URL a conectar.
En el segundo caso (USEMAP), cuando el cliente ha recibido la página HTML, tratará enteramente la detección del punto activado y la conexión con el URL. Además de la simplificación de programación, es más eficaz porque minimiza los accesos a la red.
La imagen se define con la marca IMG a la que se asocia el atributo USEMAP. Este atributo permite referenciar un "subprograma HTML" que describe las zonas activables y sus URL asociados.
La sintaxis de llamada es:

<IMG SRC="url_del_fichero.gif" USEMAP="#nombre">
El código de descripción del mapa se sitúa entre las marcas <MAP NAME="nombre"> y </MAP>
Entre estas dos marcas se definen las zonas activables por marcas <AREA SHAPE="figura" HREF="url" COORDS= X0,Y0,X1,Y1,...>
Figura puede tomar los valores RECT, POLY o CIRCL, descritas anteriormente.
