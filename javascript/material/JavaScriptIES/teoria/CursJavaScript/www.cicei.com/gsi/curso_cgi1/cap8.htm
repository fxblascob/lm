CREAR ENLACES


En HTML , una zona activa puede corresponder a un carácter, una palabra o un grupo de palabras, una imagen o una porción de imagen. El principio será idéntico: asociar a esta zona activa el URL del documento que sustituirá al documento visualizado cuando se haga click sobre esa zona. Estas zonas activas (o enlaces activables) se destacan automáticamente.

El lenguaje HTML define la noción de ancla para especificar la partida y la llegada de un enlace hipertexto.

  • ancla de partida
    • Es la zona activa donde el lector hara click para llamar a una nueva página.
  • ancla de llegada
    • Es una zona inactiva que especifica el punto de llegada de un enlace hipertexto. Esta ancla no incluye atributos visuales ya que no es una zona activable. El ancla de llegada puede estar tanto en el mismo documento como en otro.
Los enlaces internos se utilizan cuando un documento es demasiado largo para caber totalmente en la ventana del navegador (browser).
Para la definición de un ancla contamos con la marca < A >. Esta marca tiene un atributo (HREF) con cuyo valor se especifica el URL del documento a recuperar:

<A HREF="url destino"> zona activable </A>

Si el ancla de llegada está en el mismo fichero, entonces:

<A HREF="#etiqueta"> zona activable </A>

El atributo NAME define el ancla de llegada:

<A NAME="label"> zona_no_activable </A>

Los atributos HREF y NAME pueden encontrarse en un mismo ancla cuando esta ancla sea a su vez de partida y de llegada (Por ejemplo al ir a una nota de pie de página retornamos al punto desde donde se fue a esa nota):

<A HREF="#nota1" NAME="#vuelta1"> (1) </A>

Es posible describir enlaces a otros servicios de Internet:

  • FTP
    • Su URL será: FTP://nombre_servidor/directorio/subdirectorio/nombre_fichero
  • NEWS
    • NEWS://nombre_grupo_News
  • TELNET
    • TELNET://nombre_maquina
  • GOPHER
    • GHOPER://nombre_sede
  • MAILTO
    • MAILTO://nombre_destinatario@sede
