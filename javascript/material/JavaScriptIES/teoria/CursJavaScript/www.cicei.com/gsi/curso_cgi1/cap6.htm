LISTAS



HTML define dos tipos de listas:

LISTA DESCRIPTIVA:

  • <DL> .... </DL>

    Con esta marca se abre una lista descriptiva. Englobará otras dos marcas (DT y DD) cuya función es caracterizar los elementos y sus definiciones. El atributo COMPACT asociado a esta marca (<DL COMPACT>) permitirá a algún browser mostrar en la misma línea el elemento y la primera líea del bloque de descripción.

  • <DT>

    Esta marca precede a cada ítem de la lista, que no debe sobrepasar una línea. Este elemento no realiza un resalte de cada ítem de la lista,es responsabilidad del autor utilizar las marcas de estilo o de título.

  • <DD>

    La marca <DD> corresponde a la zona de definición del ítem. El tamaño de esta zona no está limitado y cada línea se sangrará hacia la derecha.

ESTRUCTURA DE UNA LISTA DESCRIPTIVA:

<DL>
<DT> Elemento 1 <DD> Descripcioón del elemento 1
<DT> Elemento 2 <DD> ...
<DT> ... <DD> ...
</DL>


LISTA REGULAR:

  • <UL> .... </UL>

    Permite generar listas no numeradas, cada uno de los elementos de la lista irá precedido por un símbolo que puede variar según el nivel de anidamiento de la lista.

  • <OL> .... </OL>

    Genera una lista ordenada o numerada.

  • <LI>

    Esta marca es común a los dos anteriores tipos de listas y precede a cada elemento de la lista.

EJEMPLO DE LISTA NO NUMERADA:

<UL>
<LI> Elemento 1
<LI> Elemento 2
...
</UL>

EJEMPLO DE LISTA NUMERADA:

<OL>
<LI> Elemento 1
<LI> Elemento 2
... </OL>

Se pueden realizar anidaciones entre todos los distintos tipos de listas.
