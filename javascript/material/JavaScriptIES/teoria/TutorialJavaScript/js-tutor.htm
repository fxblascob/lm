Manual practico de JavaScript

Con este pequeño manual pretendo cubrir el vacio existene en nuestro medio en lo referente al lenguaje JavaScript. Primero con una introduccion basica general, luego con un compacto resumen de comandos y por ultimo lo mas importante, una muy nutrida seccion de ejemplos tipicos. Si quieres bajarlo en formato ZIP mide solo 110 KB. Este manual se complementa con el de HTML
