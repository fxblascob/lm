La clausula NOSCRIPT

Hay algunos navegadores que no soportan el comando SCRIPT, por lo que podemos usar el comando NOSCRIPT.

Este comando sirve para incrustar código, el cual sera leido por el navegador que no posea la habilidad de leer JavaScript.

Es bastante util, ya que dentro de ella le podemos indicar al usuario que su navegador no interpreta JavaScript y que no podra ver ni usar la página en perfectas condiciones.

La estructura que tendría un programa de JAVA Script en el que incluyesemos el comando NOSCRIPT sería la siguiente:

<HTML>
<HEAD>
<TITLE>PROGRAMA CON CLAUSULA NOSCRIPT</TITLE>
<BODY>
<SCRIPT LANGUAJE=JavaScript>
Codigo en JavaScript
</SCRIPT>
<NOSCRIPT>
Lo siento, pero su navegador no es capaz de interpretar el lenguaje JavaScript por lo que no podrá ver la página al 100% de sus posibilidades.
>/NOSCRIPT>
>/BODY>
>/HTML>

El usuario que no posea un navegador capaz de interpretar el lenguaje JAVA Script, vera el mensaje que va entre las clausulas NOSCRIPT.

Hay que indicar que las clausulas NOSCRIPT pueden ir tanto dentro como fuera del cuerpo BODY.
