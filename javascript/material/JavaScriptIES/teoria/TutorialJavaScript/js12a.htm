Scroll en la barra de estado a la izquierda

Puedes poner el texto en una sola linea, tan larga como se quieras, siempre que este entre comillas, pero no debe de haber ningun salto de linea, si el texto es demasiado largo, es mejor dividirlo en varias lineas, tal como esta en este ejemplo.

Usaremos el evento onLoad dentro del comando <BODY> para hacer la llamada a nuestra funcion.

<HTML>
<HEAD>
<TITLE>Manual de JavaScript - Js12a</TITLE>
<SCRIPT LANGUAGE=JavaScript>
<!-- oculta codigo
var txt="<<< Este es un ejemplo de una linea que se desplaza"
+" en la barra de estado de tu navegador ! ";
function ver(){
   window.status = txt;
   txt = txt.substring(1, txt.length) + txt.charAt(0);
   window.setTimeout("ver()",150);
}
// fin oculta-->
</SCRIPT>
</HEAD>
<BODY TEXT=Navy BGCOLOR=white onLoad="ver()">
</BODY>
</HTML>
Nota: Al final de la ultima palabra del texto conviene dejar una serie de espacios en blanco, para que no este encadenado el comienzo con el final de la cadena.
