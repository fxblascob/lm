04. Document Object Model (DOM) y BOM

Tema 4: Jerarquía del navegador, temporizadores, árbol de nodos y manipulación dinámica

En esta lección:
1. BOM vs DOM 2. Elementos del BOM (window) 3. El Árbol del DOM 4. Selectores (querySelector) 5. Manipulación de Contenidos 6. Atributos y Clases CSS 7. Actividades

1. Introducción: Diferencias entre BOM y DOM

BOM (Browser Object Model)

Representa los objetos proporcionados por el navegador independientes del documento web en sí: tamaño de ventana, barras de desplazamiento, historial de navegación, temporizadores e información de geolocalización o pantalla.

DOM (Document Object Model)

Representa la estructura interna del documento HTML como un árbol jerárquico de nodos que JavaScript puede inspeccionar, alterar, añadir o eliminar en tiempo real.

2. Elementos Principales del BOM (Objeto window)

El objeto window es el objeto global supremo en el navegador. Todos los identificadores y funciones estándar (como alert, console, o document) cuelgan de él.

Temporizadores e Intervalos

setTimeout(funcion, retardoMs)

Ejecuta la función una sola vez tras transcurrir los milisegundos indicados:

let timerId = setTimeout(() => {
    console.log("Han pasado 3 segundos");
}, 3000);

// Para cancelar antes de que se dispare:
clearTimeout(timerId);
setInterval(funcion, intervaloMs)

Ejecuta la función de forma periódica y repetitiva cada N milisegundos:

let relojId = setInterval(() => {
    console.log(new Date().toLocaleTimeString());
}, 1000);

// Para detener el bucle:
clearInterval(relojId);

3. El Árbol del Documento (DOM)

Cuando el navegador procesa un archivo HTML, crea en memoria un árbol de objetos donde cada etiqueta, texto y atributo se convierte en un nodo:

  • Nodo Documento: La raíz del árbol accesible como document.
  • Nodos Elemento: Cada una de las etiquetas HTML (<html>, <body>, <p>, <div>).
  • Nodos Texto: El contenido alfanumérico contenido dentro de una etiqueta.
  • Nodos Atributo: Las propiedades de las etiquetas (ej. id, class, src).

4. Selección de Nodos: querySelector y querySelectorAll

Los métodos estándar y recomendados por W3C permiten localizar elementos del DOM reutilizando exactamente los mismos selectores de CSS:

Método de Selección Devuelve Ejemplo de Uso
document.querySelector(selector) El primer elemento coincidente o null. document.querySelector("#btnEnviar");
document.querySelectorAll(selector) Una NodeList estática con todas las coincidencias. document.querySelectorAll(".card p.lead");
document.getElementById(id) El elemento con ese identificador exacto (método clásico rápido). document.getElementById("menuPrincipal");

5. Manipulación Dinámica: Crear, Modificar y Borrar

Crear e Insertar Elementos
// 1. Crear el nuevo elemento
const nuevoParrafo = document.createElement("p");

// 2. Asignar contenido textual seguro
nuevoParrafo.textContent = "Texto generado dinámicamente";

// 3. Insertar en el contenedor padre
const contenedor = document.querySelector("#seccion");
contenedor.appendChild(nuevoParrafo);
Modificar y Eliminar Elementos
// Modificar texto seguro
elemento.textContent = "Nuevo contenido";

// Modificar HTML interno (usar con precaución por XSS)
elemento.innerHTML = "<strong>Resaltado</strong>";

// Eliminar el elemento del árbol
elemento.remove();

6. Manipulación de Atributos y Clases CSS

Gestión de Clases con classList
// Añadir clase
el.classList.add("activo", "shadow");

// Quitar clase
el.classList.remove("oculto");

// Alternar (toggle: pone si falta, quita si está)
el.classList.toggle("dark-mode");

// Comprobar si existe
if (el.classList.contains("activo")) { ... }
Atributos HTML y dataset
// Atributos generales
img.setAttribute("src", "foto.jpg");
let src = img.getAttribute("src");
img.removeAttribute("alt");

// Atributos de datos (data-*)
// HTML: <div data-id="42" data-user="ana">
console.log(div.dataset.id);   // "42"
console.log(div.dataset.user); // "ana"
