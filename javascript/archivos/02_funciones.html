02. Funciones y Modularidad

Tema 2: Declaración, parámetros, ámbito (scope), funciones útiles y arrow functions

En esta lección:
1. Definición y Parámetros 2. Valores de Retorno 3. Ámbito de Variables 4. Manejo de Strings 5. Funciones Matemáticas 6. Trabajo con Fechas 7. Funciones Flecha (Lambdas) 8. Actividades

1. Definición de Funciones y Parámetros

Una función es un bloque de código reutilizable diseñado para realizar una tarea específica. Su empleo permite estructurar el código en componentes manejables, facilitar el mantenimiento y cumplir el principio DRY (Don't Repeat Yourself).

// Declaración tradicional de una función
function saludar(nombre) {
    console.log("¡Hola, " + nombre + "!");
}

// Invocación o llamada pasando un argumento real
saludar("Lucía"); // Muestra: ¡Hola, Lucía!

Parámetros por defecto (ES6)

A partir de ECMAScript 2015, es posible asignar valores por omisión a los parámetros formales para cuando no se suministren en la llamada o sean undefined:

function calcularPrecio(base, iva = 0.21) {
    return base + (base * iva);
}

console.log(calcularPrecio(100));       // 121 (aplica iva por defecto 21%)
console.log(calcularPrecio(100, 0.10)); // 110 (sobrescribe con iva reducido 10%)

2. Valores de Retorno con return

La sentencia return finaliza inmediatamente la ejecución de la función y devuelve un valor al punto de llamada. Si una función no incluye return, devuelve de forma implícita undefined.

function esPar(numero) {
    if (numero % 2 === 0) {
        return true;
    }
    return false;
}

let resultado = esPar(7); // false

3. Ámbito de Variables: Locales vs Globales

Variables Locales (Bloque)

Declaradas con let o const dentro de una función o bloque { ... }. Solo son accesibles dentro de dicho bloque y se destruyen al finalizar.

function test() {
    let local = "Privada";
}
// console.log(local); // ReferenceError
Variables Globales

Declaradas fuera de cualquier función. Son accesibles desde cualquier lugar del script. Conviene minimizar su uso para evitar colisiones de nombres accidentales.

let global = "Pública";
function ver() {
    console.log(global); // Funciona
}

4. Funciones Predefinidas para Manejo de Cadenas (Strings)

Método / Propiedad Descripción Ejemplo de Resultado
cadena.length Longitud (número total de caracteres). "Hola".length // 4
toUpperCase() / toLowerCase() Conversión a mayúsculas o minúsculas. "js".toUpperCase() // "JS"
indexOf(subcadena) Primera posición donde aparece la subcadena (-1 si no existe). "web".indexOf("e") // 1
includes(subcadena) Determina si una cadena contiene otra (booleano). "hola mundo".includes("mundo") // true
substring(inicio, fin) Extrae la porción entre dos índices numéricos. "LMSGI".substring(0, 2) // "LM"
split(separador) Divide el string en un array de subcadenas según el delimitador. "a,b,c".split(",") // ["a","b","c"]
trim() Elimina espacios en blanco al inicio y final. " test ".trim() // "test"

5. El Objeto Matemático Math

El objeto nativo Math proporciona constantes matemáticas y funciones de cálculo numérico comunes:

Redondeos Math.round(4.7) // 5
Math.floor(4.9) // 4 (hacia abajo)
Math.ceil(4.1) // 5 (hacia arriba)
Aleatorios Math.random() devuelve un número decimal pseudoaleatorio en el intervalo [0, 1).
Extremos y Potencias Math.max(10, 5, 20) // 20
Math.min(10, 5, 20) // 5
Math.pow(2, 3) // 8

6. Trabajo con Fechas (Objeto Date)

El constructor new Date() permite manipular instantes temporales, fechas y horas:

let ahora = new Date();
console.log("Año actual: " + ahora.getFullYear());
console.log("Mes (0 a 11): " + ahora.getMonth());
console.log("Día del mes (1 a 31): " + ahora.getDate());
console.log("Hora: " + ahora.getHours() + ":" + ahora.getMinutes());

7. Funciones Anónimas y Funciones Flecha (Arrow Functions)

Expresión de Función Anónima

Una función asignada directamente a una variable sin nombre propio:

const multiplicar = function(a, b) {
    return a * b;
};
Función Flecha (Arrow Function ES6)

Sintaxis concisa con el operador => y retorno implícito en expresiones de una sola línea:

// Versión compacta
const multiplicar = (a, b) => a * b;

// Con un solo parámetro no requiere paréntesis
const cuadrado = x => x * x;
