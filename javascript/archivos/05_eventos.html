5.1

Eventos y Programación Tradicional

Los programas tradicionales ejecutan una secuencia estricta de instrucciones una tras otra de principio a fin. En el desarrollo web, las aplicaciones necesitan reaccionar en tiempo real a las acciones impredecibles del usuario (hacer clic, arrastrar, mover el ratón, teclear) o a cambios de estado del documento (finalización de carga, redimensionamiento).

Este paradigma se denomina programación dirigida por eventos (event-driven programming). Un evento es una notificación emitida por el navegador a la que podemos suscribir una función manejadora (event handler o listener) para que ejecute una respuesta inmediata.

5.2

Principales Familias de Eventos

A continuación se clasifican los eventos nativos más relevantes según su ámbito:

Categoría Nombre del Evento Momento en que se Dispara
Ventana / Documento load El documento HTML, imágenes y hojas de estilo han terminado de cargarse por completo.
beforeunload / unload Se produce antes o durante el cierre o navegación fuera de la pestaña actual.
resize / scroll Se modifica el tamaño de la ventana o se realiza desplazamiento en la vista.
Teclado keydown El usuario presiona una tecla (se repite si se mantiene pulsada).
keyup El usuario suelta la tecla previamente pulsada.
keypress Combinación de pulsar y soltar (deprecated, se desaconseja en favor de keydown).
Ratón (Mouse) click / dblclick Pulsación simple o doble clic sobre cualquier elemento.
mousedown / mouseup Se aprieta o se libera cualquier botón del ratón.
mouseenter / mouseleave El puntero entra o sale de la superficie de un elemento delimitado.
mousemove El ratón se desplaza continuamente sobre el elemento.
Formularios focus / blur Un control interactivo (input, select) recibe o pierde el foco.
change / input El valor del campo cambia tras perder el foco (change) o en cada pulsación (input).
submit / reset Se solicita el envío o el restablecimiento de los campos de un <form>.
5.3

Estrategias para Vincular Manejadores de Eventos

A lo largo de la historia de JavaScript se han utilizado cuatro métodos para asociar código a un evento:

1. Atributo HTML Directo

Código incrustado en el HTML. Muy desaconsejado por ensuciar el marcado:

<button onclick="alert('Hola');">Pulsar</button>
2. Atributo HTML llamando a Función

Separa la función pero sigue ensuciando el HTML con atributos on...:

<div onmouseenter="cambiar(this)">...</div>
3. Propiedad del Objeto DOM

HTML limpio, pero solo admite un único manejador (el último asignado sobreescribe al anterior):

let btn = document.getElementById("btn1");
btn.onclick = function() { ... };
4. Escuchadores con addEventListener (Estándar Profesional)

Permite múltiples escuchadores independientes sobre un mismo evento, separar capas y definir fases:

btn.addEventListener('click', function(e) {
    this.classList.toggle("activo");
});

5.4.1

Propagación Jerárquica: Bubbling vs Capturing

Dado que los elementos del DOM están anidados unos dentro de otros (por ejemplo: <div> > <p> > <img>), cuando se pulsa sobre la imagen el evento se propaga por toda la jerarquía de ancestros:

Bubbling (Burbujeo - Por Defecto)

El evento sube como una burbuja desde el elemento más específico (la imagen) hacia el contenedor más general (p y luego div): 

elem.addEventListener("click", fn); // 3er parámetro false
Capturing (Captura)

El evento baja desde el ancestro más general hacia el objetivo concreto, activando el 3er parámetro en true: 

elem.addEventListener("click", fn, true);

5.4.2

El Objeto Event (Información de la Interacción)

Toda función manejadora recibe automáticamente como primer argumento el objeto Event (habitualmente nombrado e o event), que contiene las propiedades físicas y temporales del evento ocurrido:

Propiedad / Método Información que Proporciona
e.clientX / e.clientYCoordenadas relativas a la ventana del navegador.
e.pageX / e.pageYCoordenadas absolutas respecto al documento entero (incluyendo scroll).
e.targetEl elemento exacto del DOM donde se originó el clic o evento.
e.key / e.codeCarácter tecleado y código físico de la tecla pulsada.
e.altKey / e.ctrlKey / e.shiftKeyBooleanos que indican si se mantenía pulsada dicha tecla modificadora.
e.preventDefault()Anula la acción por defecto (ej. evita que un enlace navegue o un formulario recargue).
e.stopPropagation()Detiene la propagación del evento por el árbol de ancestros.

5.4.3

API Nativa de Arrastrar y Soltar (Drag & Drop)

HTML5 y JavaScript proporcionan una API nativa para arrastrar elementos en la pantalla sin librerías externas:

  1. El elemento arrastrable debe tener el atributo draggable="true".
  2. En el evento dragstart, guardamos el identificador del elemento en e.dataTransfer.setData("id", e.target.id).
  3. En el contenedor de destino, escuchamos dragover y llamamos a e.preventDefault() para permitir soltar.
  4. En el evento drop, recuperamos el dato con e.dataTransfer.getData("id") y añadimos el nodo con appendChild.

5.4.4

Encapsulación de Código y Patrón IIFE

Para evitar contaminar el ámbito global de window y prevenir colisiones de nombres con otras librerías, los desarrolladores encapsulan sus scripts mediante una IIFE (Immediately Invoked Function Expression): 

(function() {
    // Todas las variables y funciones definidas aquí son 100% privadas:
    let contadorPrivado = 0;
    document.getElementById("btn").addEventListener("click", () => {
        contadorPrivado++;
        console.log(contadorPrivado);
    });
})(); // Se auto-ejecuta de inmediato
