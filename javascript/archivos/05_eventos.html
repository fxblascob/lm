05. Gestión de Eventos e Interactividad

Tema 5: Modelo de eventos, addEventListener, propagación y Drag & Drop

En esta lección:
1. Modelo de Eventos 2. Tipos de Eventos 3. addEventListener 4. El Objeto Event 5. Flujo de Propagación 6. Drag & Drop 7. Actividades

1. Eventos y Programación Reactiva

En el desarrollo web moderno, la ejecución no es lineal ni secuencial: se basa en una arquitectura dirigida por eventos (*Event-Driven*). El navegador monitoriza constantemente el entorno y notifica a JavaScript cuando el usuario hace clic, pulsa una tecla, redimensiona la ventana o cuando termina de cargarse una imagen.

2. Principales Categorías de Eventos

Categoría Nombre del Evento Momento en que se Dispara
Ventana y Carga DOMContentLoaded, load, resize, scroll El árbol DOM está parseado; la página y recursos están totalmente cargados; cambio de tamaño o desplazamiento.
Ratón (*Mouse*) click, dblclick, mouseenter, mouseleave Clic izquierdo, doble clic, puntero entra o sale del área delimitadora del elemento.
Teclado (*Keyboard*) keydown, keyup Una tecla física se presiona o se libera. Permite leer event.key y event.code.
Formularios submit, input, change, focus, blur Envío del formulario, cambio de texto en tiempo real, pérdida o ganancia de foco.

3. Registro de Manejadores con addEventListener

El estándar W3C estipula el método addEventListener() como el mecanismo oficial para asociar funciones escuchadoras (*listeners*). Permite vincular múltiples manejadores al mismo evento sin sobreescribirse entre sí:

const boton = document.querySelector("#btnSaludar");

// Sintaxis: elemento.addEventListener(tipoEvento, callback, opciones)
boton.addEventListener("click", function(event) {
    console.log("¡Botón pulsado!");
});

// Con función flecha
boton.addEventListener("mouseenter", () => {
    boton.classList.add("shadow-lg");
});

4. El Objeto Event

El navegador pasa automáticamente un objeto event como primer parámetro a la función escuchadora, con abundante información sobre la acción acontecida:

event.target El elemento HTML exacto que originó el evento (el nodo sobre el que se hizo clic).
event.preventDefault() Cancela la acción predeterminada del navegador (como seguir un enlace <a> o enviar un formulario).

5. Flujo de Propagación: Bubbling y Capturing

Cuando un evento ocurre en un elemento anidado dentro de otros, viaja a través del árbol DOM en dos fases:

1. Fase de Burbujeo (*Bubbling* - Predeterminada)

El evento se dispara primero en el elemento más interno (origen) y luego asciende progresivamente por todos sus ancestros hasta window.

// Para detener el ascenso a padres:
event.stopPropagation();
2. Fase de Captura (*Capturing*)

El evento desciende desde window hasta el elemento objetivo antes de que comience el burbujeo. Se activa pasando { capture: true } en addEventListener.

6. API de Arrastrar y Soltar (Drag and Drop)

HTML5 y JavaScript incluyen soporte nativo para arrastrar elementos en la interfaz:

// 1. Marcar elemento como arrastrable
// HTML: <div id="item" draggable="true">Arrastra aquí</div>

item.addEventListener("dragstart", (e) => {
    e.dataTransfer.setData("text/plain", e.target.id);
});

zonaDestino.addEventListener("dragover", (e) => {
    e.preventDefault(); // Imprescindible para permitir soltar
});

zonaDestino.addEventListener("drop", (e) => {
    e.preventDefault();
    const id = e.dataTransfer.getData("text/plain");
    zonaDestino.appendChild(document.getElementById(id));
});
