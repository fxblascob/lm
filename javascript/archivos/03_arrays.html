03. Arrays y Objetos

Tema 3: Colecciones, referencias, métodos modernos, ordenación y objetos

En esta lección:
1. Creación de Arrays 2. Paso por Referencia 3. Recorrido de Arrays 4. Operaciones Básicas 5. Ordenación (sort) 6. Métodos Modernos (map/filter) 7. Objetos Literales 8. Actividades

1. Creación y Acceso a Arrays

Un array es una estructura de datos ordenada capaz de albergar una colección de elementos indexados secuencialmente a partir del índice 0. En JavaScript, los arrays son dinámicos (crecen o decrecen en tiempo de ejecución) y pueden almacenar tipos de datos heterogéneos.

// Declaración literal recomendada
let frutas = ["Manzana", "Plátano", "Naranja"];

console.log(frutas[0]);      // "Manzana" (primer elemento)
console.log(frutas.length); // 3 (número de elementos)

// Modificación de un elemento
frutas[1] = "Pera";
console.log(frutas);        // ["Manzana", "Pera", "Naranja"]

2. Asignación y Paso por Referencia

Comportamiento de memoria crucial: A diferencia de los tipos primitivos (números, strings) que se copian por valor, los arrays y objetos se copian y asignan por referencia. Dos variables que apunten al mismo array compartirán el mismo objeto subyacente.
Asignación por Referencia
let a = [1, 2, 3];
let b = a; // Copia la referencia
b.push(4);
console.log(a); // [1, 2, 3, 4] ¡Afecta a ambos!
Clonación Independiente (Spread Operator)
let a = [1, 2, 3];
let b = [...a]; // Clon superficial
b.push(4);
console.log(a); // [1, 2, 3] ¡Intacto!

3. Métodos para Recorrer Arrays

1. Bucle for tradicional

Permite control exacto de índices, saltos y dirección inversa.

for (let i = 0; i < a.length; i++) {
    console.log(a[i]);
}
2. Bucle for...of (ES6)

Sintaxis directa y limpia para iterar directamente sobre los valores.

for (const item of a) {
    console.log(item);
}
3. Método forEach()

Enfoque funcional que recibe una función callback con elemento e índice.

a.forEach((val, idx) => {
    console.log(idx + ": " + val);
});

4. Operaciones Esenciales de Mutación

Operación Método Efecto sobre el Array
Añadir al final array.push(elem) Inserta uno o más elementos al final.
Quitar del final array.pop() Extrae y devuelve el último elemento.
Añadir al inicio array.unshift(elem) Inserta elementos al principio desplazando los demás.
Quitar del inicio array.shift() Extrae y devuelve el primer elemento.
Modificación intermedia array.splice(inicio, cantidad, ...nuevos) Elimina o inserta elementos en cualquier posición intermedia.
Unir en texto array.join(separador) Concatena todos los elementos en un string separado por delimitador.

5. Ordenación con sort()

El método sort() ordena los elementos del array in situ (modifica el original). Sin embargo, por defecto convierte los elementos a texto y los ordena alfabéticamente según código Unicode, produciendo resultados inesperados con números:

Comportamiento por Defecto (Texto)
let nums = [10, 5, 40, 25, 1000];
nums.sort();
console.log(nums); 
// [10, 1000, 25, 40, 5] ¡Incorrecto numéricamente!
Con Función de Comparación
let nums = [10, 5, 40, 25, 1000];
// Función comparadora: (a - b) para orden ascendente
nums.sort((a, b) => a - b);
console.log(nums); 
// [5, 10, 25, 40, 1000] ¡Correcto!

6. Métodos Funcionales Modernos: map, filter y find

map()

Transforma cada elemento y devuelve un nuevo array con los resultados:

const nums = [1, 2, 3];
const dobles = nums.map(x => x * 2);
// [2, 4, 6]
filter()

Filtra y devuelve un nuevo array con los elementos que cumplan el predicado:

const nums = [5, 12, 8, 130];
const mayores = nums.filter(x => x >= 10);
// [12, 130]
find()

Devuelve el primer elemento que coincida con la condición o undefined:

const users = [{id:1}, {id:2}];
const u = users.find(x => x.id === 2);
// {id: 2}

7. Objetos Literales en JavaScript

Un objeto es una estructura no indexada de pares clave: valor. Permite agrupar propiedades y funciones (métodos) bajo una entidad:

// Declaración de objeto literal
const persona = {
    nombre: "Carlos",
    edad: 28,
    ciudad: "Valencia",
    saludar: function() {
        return "Hola, soy " + this.nombre;
    }
};

// Acceso a propiedades mediante notación por punto y corchetes
console.log(persona.nombre);      // "Carlos"
console.log(persona["ciudad"]);  // "Valencia"
console.log(persona.saludar());  // "Hola, soy Carlos"
