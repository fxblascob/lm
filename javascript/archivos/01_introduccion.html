01. Introducción y Programación Básica

Tema 1: Fundamentos, inclusión en HTML, sintaxis, variables y control de flujo

1. ¿Qué es JavaScript?

JavaScript es un lenguaje de programación interpretado, ligero y orientado a objetos basado en prototipos, diseñado originalmente para ejecutarse en el navegador web del cliente. Su propósito fundamental es dotar de dinamismo e interactividad a las páginas web que, con solo HTML y CSS, serían documentos estáticos.

HTML

Define la estructura y el contenido semántico de la página web (encabezados, párrafos, tablas, formularios).

CSS

Controla la presentación visual y el diseño adaptable (colores, fuentes, modelo de cajas, flexbox, rejilla).

JavaScript

Gestiona el comportamiento, lógica e interactividad en respuesta a acciones del usuario o eventos asíncronos.

Nota histórica y técnica: A pesar de la similitud en el nombre, JavaScript no guarda relación con el lenguaje Java de Oracle. JavaScript fue creado en 1995 por Brendan Eich en Netscape bajo el nombre de Mocha (luego LiveScript) y estandarizado internacionalmente bajo la especificación ECMAScript (ES).

2. Cómo incluir JavaScript en documentos HTML

Existen tres métodos principales para integrar código JavaScript en una página web:

El código se introduce directamente entre las etiquetas <script> y </script>. Es ideal para scripts pequeños o específicos de una sola página.

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Código en el propio documento</title>
    <script>
        console.log("¡Hola mundo desde JavaScript!");
    </script>
</head>
<body>
    <p>Contenido de la página.</p>
</body>
</html>

Se escribe el código en un archivo independiente con extensión .js y se referencia con el atributo src. Permite reutilizar el código entre múltiples páginas y aprovecha la memoria caché del navegador.

<!-- En el documento HTML -->
<script src="js/codigo.js"></script>

// En el archivo js/codigo.js
alert("¡Mensaje cargado desde archivo externo!");

Incrustar código en atributos como onclick o onmouseover mezcla estructura y comportamiento, dificultando el mantenimiento. En desarrollo moderno se sustituye siempre por addEventListener().

<button onclick="alert('Acción ejecutada')" class="btn btn-primary">Pulsar aquí</button>

3. Ubicación de scripts y la etiqueta <noscript>

¿Dónde colocar <script>?
  • Al final del <body> (Recomendado clásico): Permite que todo el HTML se parsee y visualice antes de que el script se descargue y ejecute, evitando sensaciones de lentitud.
  • En el <head> con defer (Estándar moderno): Al añadir el atributo defer (<script src="..." defer>), el navegador descarga el archivo en segundo plano sin bloquear el renderizado y lo ejecuta ordenadamente justo al finalizar la carga del DOM.
La etiqueta <noscript>

Define un bloque de contenido alternativo que solo se muestra a usuarios que naveguen con JavaScript desactivado o en navegadores que no lo soporten:

<noscript>
    <div class="alert alert-warning">
        Esta aplicación requiere JavaScript para funcionar correctamente.
    </div>
</noscript>

4. Detección de errores y Consola del Desarrollador

A diferencia de los lenguajes compilados (como C o Java), JavaScript no genera un ejecutable previo. Los errores sintácticos o lógicos se manifiestan en tiempo de ejecución en el navegador. La herramienta principal de depuración es la Consola Web (accesible pulsando F12 o Ctrl + Mayús + I en Chrome, Firefox o Edge).

Instrucción de Consola Propósito y Comportamiento
console.log(mensaje, valor) Imprime información general y valores de variables para inspección rápida.
console.error(error) Muestra un mensaje resaltado en rojo con la traza de la pila de llamadas (*stack trace*).
console.warn(aviso) Emite una advertencia visual destacada en amarillo.
console.table(array_u_objeto) Representa colecciones tabulares de objetos en una tabla visual limpia.

5. Reglas de Sintaxis Básica

  • Sensibilidad a mayúsculas (*Case Sensitive*): Las variables miVariable, Mivariable y mivariable son tres identificadores totalmente diferentes.
  • Punto y coma (;): Separa sentencias ejecutables. Aunque JavaScript posee inserción automática de punto y coma (ASI), es una buena práctica incluirlo explícitamente para evitar ambigüedades.
  • Comentarios: De una línea con doble barra (// comentario) o en bloque multilínea (/* comentario */).

6. Comunicación con el Usuario: Diálogos Modales

JavaScript en navegadores proporciona tres funciones nativas del objeto window para interactuar rápidamente con el usuario de manera síncrona:

alert(mensaje)

Abre una ventana emergente informativa con un botón de aceptar. Detiene la ejecución hasta que se pulsa.

alert("¡Operación exitosa!");
confirm(pregunta)

Muestra una pregunta con botones de Aceptar y Cancelar. Devuelve true o false.

let borrar = confirm("¿Desea eliminar?");
prompt(texto, defecto)

Solicita la entrada de un texto por teclado. Devuelve la cadena introducida o null si cancela.

let nombre = prompt("¿Tu nombre?");

7. Variables y Tipos de Datos

Una variable es un contenedor con nombre para almacenar datos en memoria. En JavaScript moderno se emplean dos palabras clave principales:

Palabra clave Ámbito (*Scope*) Reasignable Buenas Prácticas
const Bloque ({ ... }) No (constante) Recomendado Usar por defecto siempre que la variable no cambie de valor.
let Bloque ({ ... }) Sí Recomendado Usar cuando el valor deba mutar (contadores, acumuladores).
var Función o Global Sí Obsoleto Evitar en código moderno por problemas de elevación (*hoisting*).

Tipos de Datos Primitivos

Number Enteros y decimales de coma flotante (ej. 42, 3.1415).
String Cadenas de caracteres entre comillas simples, dobles o template literals (`hola`).
Boolean Valores lógicos de verdad o falsedad: true o false.
Null / Undefined undefined (variable sin inicializar) y null (ausencia explícita de valor).
Conversión de tipos: Las lecturas de prompt() siempre son cadenas de texto. Para operar numéricamente, debemos convertir explícitamente usando Number(valor), parseInt(valor, 10) o parseFloat(valor).

8. Operadores en JavaScript

Operadores Aritméticos y Asignación
  • + Suma (o concatenación si hay strings)
  • -, *, / Resta, producto y división real
  • % Módulo (resto de la división entera, ej. 10 % 3 = 1)
  • ** Exponenciación (ej. 2 ** 3 = 8)
  • ++, -- Incremento y decremento unario
  • +=, -=, *= Asignación compuesta
Comparación Estricta y Lógicos
  • === y !== Igualdad y desigualdad estricta (compara valor Y tipo sin coerción).
  • == y != Igualdad abstracta con coerción implícita (evitar).
  • && AND lógico (ambas condiciones verdaderas).
  • || OR lógico (al menos una condición verdadera).
  • ! Negación lógica invertida (NOT).

9. Estructuras de Control de Flujo

Condicionales (if / else / switch)
let edad = 18;
if (edad >= 18) {
    console.log("Mayor de edad");
} else {
    console.log("Menor de edad");
}

switch (dia) {
    case 1: console.log("Lunes"); break;
    case 2: console.log("Martes"); break;
    default: console.log("Otro día");
}
Bucles e Iteraciones (for / while)
// Bucle for clásico
for (let i = 0; i < 5; i++) {
    console.log("Iteración: " + i);
}

// Bucle while con condición previa
let n = 1;
while (n <= 3) {
    console.log("Paso: " + n);
    n++;
}
