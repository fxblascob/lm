1.1

¿Qué es JavaScript?

JavaScript es un lenguaje de programación que se utiliza principalmente para crear páginas web dinámicas.

Una página web dinámica es aquella que incorpora efectos interactivos como textos que aparecen y desaparecen, animaciones visuales, acciones que se activan al pulsar botones, galerías multimedia y ventanas emergentes con mensajes de aviso al usuario.

Lenguaje Interpretado

Técnicamente, JavaScript es un lenguaje de programación interpretado en tiempo de ejecución por el motor del navegador (como V8 en Chrome/Edge o SpiderMonkey en Firefox). Por tanto, no es necesario compilar los programas antes de probarlos: se ejecutan de forma inmediata al abrir o refrescar el documento HTML.

Aclaración: JavaScript no es Java

A pesar de su nombre, JavaScript no guarda ninguna relación directa con el lenguaje de programación Java. Legalmente, JavaScript es una marca registrada originaria de la empresa Sun Microsystems (actualmente Oracle).

1.2

Cómo incluir JavaScript en documentos HTML

Existen tres mecanismos estándar para incorporar código JavaScript dentro de un sitio web. A continuación analizamos cada uno en detalle:

1.2.1 En el mismo documento

El código JavaScript se encierra entre etiquetas <script> y </script> y se puede situar en cualquier parte del documento. Aunque es técnicamente correcto incluir bloques de código en cualquier zona de la página, habitualmente se ha definido dentro de la cabecera del documento (dentro de la etiqueta <head>): 

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Ejemplo de código JavaScript en el propio documento</title>
    <script>
        console.log("Hola mundo");
    </script>
</head>
<body>
    <p>Un párrafo de texto.</p>
</body>
</html>

1.2.2 En un archivo externo (Recomendado)

Mejor Práctica

Los archivos de código JavaScript son documentos normales de texto plano guardados con la extensión .js, que se pueden crear y editar con cualquier editor (Visual Studio Code, Notepad++, Nano, etc.).

Archivo: codigo.js 
alert("Un mensaje de prueba");
Documento HTML (index.html) 
<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Enlace a script externo</title>
    <script src="/js/codigo.js"></script>
</head>
<body>
    <p>Un párrafo de texto.</p>
</body>
</html>
Ventajas clave:
  • Simplifica y limpia la estructura del documento HTML.
  • Permite reutilizar y cachear el mismo archivo JavaScript en todas las páginas de la aplicación.
  • Favorece la separación de responsabilidades (estructura en HTML, estilo en CSS y comportamiento en JS).

1.2.3 Dentro de elementos del HTML (Inline)

Desaconsejado

Consiste en incrustar fragmentos de JavaScript directamente en atributos de evento de etiquetas HTML: 

<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>Código inline</title>
</head>
<body>
    <p onclick="alert('Un mensaje de prueba')">Un párrafo de texto.</p>
</body>
</html>

Inconveniente principal: Ensucia innecesariamente el marcado HTML y complica enormemente el mantenimiento del código. En el desarrollo moderno solo se utiliza en casos muy aislados; la forma profesional es vincular escuchadores con addEventListener desde archivos externos.

1.3

Ubicación de las etiquetas <script>

Al incluir archivos JavaScript externos o bloques propios, conviene tener muy presente en qué posición colocarlos dentro del árbol del documento HTML:

En la cabecera (<head>)

Adecuado si el script únicamente contiene definiciones de funciones que se activarán o lanzarán más adelante conforme el usuario interactúe con los botones o formularios de la página.

Al final del cuerpo (antes de </body>)

Altamente recomendado si el script contiene instrucciones que necesitan ejecutarse inmediatamente al cargar o si manipula elementos del DOM. Así se garantiza que todo el HTML ya ha sido renderizado antes de que el script intente buscarlo.

Atributos modernos de carga asíncrona: En HTML5 también disponemos de los atributos defer (descarga en segundo plano y ejecuta en orden una vez procesado el DOM) y async (descarga y ejecuta inmediatamente sin orden garantizado), colocados dentro de <script src="..." defer>.
1.4

La etiqueta <noscript>

Algunos navegadores no disponen de soporte completo para JavaScript, otros permiten bloquearlo mediante extensiones y algunos usuarios deshabilitan activamente su ejecución por motivos de privacidad o accesibilidad.

El estándar HTML define la etiqueta <noscript> para mostrar un mensaje informativo o un diseño alternativo cuando el navegador del usuario no puede ejecutar JavaScript: 

<body>
    <noscript>
        <div class="aviso-noscript">
            <p><strong>Bienvenido a Mi Sitio</strong></p>
            <p>
                La página que estás viendo requiere para su correcto funcionamiento el uso de JavaScript.
                Si lo has deshabilitado intencionadamente, por favor vuelve a activarlo en la configuración de tu navegador.
            </p>
        </div>
    </noscript>
    
    <!-- Resto del contenido habitual de la página -->
</body>

La etiqueta <noscript> se debe incluir en el interior de <body> (habitualmente al principio). El contenido dentro de ella puede contener cualquier elemento HTML (párrafos, encabezados, enlaces, imágenes).

1.5

Detectar errores en JavaScript

A diferencia de los programas de escritorio (como los creados en C o Java), en lenguajes web que corren en el cliente como JavaScript no existe una ventana de terminal nativa abierta de forma predeterminada para ver las trazas de ejecución.

Todos los navegadores web modernos (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari) incluyen Herramientas para Desarrolladores (DevTools) que se abren pulsando la tecla F12 o haciendo clic derecho sobre la página y seleccionando Inspeccionar.

1.5.1 Consola y mensajes de depuración

La pestaña Console (Consola) de las DevTools es la herramienta más útil para programar en JavaScript, pues informa en tiempo real de los fallos sintácticos, excepciones y referencias no definidas.

Además de la instrucción clásica alert() (que bloquea la pantalla con una ventana emergente modal), podemos utilizar métodos del objeto console para enviar información sin interrumpir la navegación del usuario: 

// 1. Mensaje de log informativo general
console.log("El script se ha inicializado correctamente.");

// 2. Mensaje de error destacado en rojo en la consola
console.error("El email está vacío");

// 3. Advertencia amarilla
console.warn("Atención: este campo es obligatorio para envíos internacionales.");
1.6

Sintaxis Fundamental de JavaScript

La sintaxis es el conjunto de normas y reglas que determinan cómo deben escribirse las instrucciones para que el intérprete las considere válidas. Es muy parecida a la de lenguajes como C, C++ y Java:

Regla de Sintaxis Descripción y Pauta de Buenas Prácticas
Espacios en blanco y saltos El intérprete ignora los espacios y saltos de línea sobrantes. Se pueden tabular las líneas y espaciar los bloques para facilitar la legibilidad del código.
Distinción de mayúsculas (Case-sensitive) JavaScript distingue estrictamente mayúsculas de minúsculas. Las variables miNumero, minumero y MINUMERO son tres identificadores totalmente diferentes.
Tipado dinámico No se indica el tipo de dato al declarar una variable (no hay int, float o string como en Java). Una misma variable puede almacenar un número y luego un texto a lo largo de su ciclo de vida.
Punto y coma ( ; ) Aunque JavaScript cuenta con inserción automática de punto y coma (ASI), es una buena práctica obligatoria terminar cada sentencia con ; para evitar errores imprevistos al comprimir o minificar scripts.
Comentarios de código Se admiten dos modalidades de comentarios para documentar la lógica:
  • Una sola línea: precedidos por dos barras // Comentario.
  • Multilínea: encerrados entre /* ... */.
 
// Ejemplo de comentario de una sola línea
alert("Mensaje de prueba");

/* Los comentarios de varias líneas son muy útiles 
   cuando se necesita detallar la lógica o explicar
   el funcionamiento de algoritmos complejos */
alert("Segundo mensaje");

1.8

Programación Básica en JavaScript

En esta sección se estudian los bloques de construcción esenciales: entrada y salida de datos, variables, tipos primitivos, coerción y operadores.

1.8.1 Métodos de Comunicación con el Usuario

JavaScript ofrece varios mecanismos directos para intercambiar información con el usuario y con el entorno de desarrollo:

Instrucción Destino / Comportamiento Ejemplo de Código
alert(mensaje) Muestra una ventana emergente modal que detiene la ejecución hasta pulsar Aceptar. alert("Hola, buenos días");
console.log(msg) / console.error(msg) Escribe en la consola interna de depuración del navegador sin molestar al usuario. console.log("Datos cargados");
document.write(html) Escribe contenido de texto o etiquetas directamente en el flujo del documento HTML. document.write("<p>Texto HTML</p>");
prompt(mensaje) Abre un cuadro emergente con un campo de texto para que el usuario escriba un dato. Devuelve una cadena de texto (String) o null si el usuario pulsa en Cancelar. let nombre = prompt("Dime tu nombre:"); 
let nombre = prompt("Dime tu nombre");
if (nombre !== null) {
    alert("Hola " + nombre + ", ¡bienvenido al curso!");
}

1.8.2 Variables y Buenas Prácticas

Las variables se emplean para almacenar valores en memoria que pueden variar a lo largo de la ejecución. Existen tres formas de crearlas en JavaScript:

Sintaxis Estado Comportamiento y Ámbito
let n1 = 5; Aconsejado Crea una variable local restringida al bloque de código actual { ... }. Evita colisiones de nombres.
var n2 = 5; Desaconsejado Forma clásica anterior a ES6. Posee ámbito de función (function scope) o global, y sufre de hoisting confuso.
n3 = 5; Muy Desaconsejado Asignación directa sin declarar. Crea una variable global implícita propensa a errores graves.

Declaración vs Inicialización

La palabra reservada let solo debe indicarse al definir por primera vez la variable (declaración). Si al declarar se le asigna un valor inicial, decimos que ha sido inicializada: 

// Declaración separada de la asignación:
let numero_1;
let numero_2;

numero_1 = 3;
numero_2 = 1;

// Declaración e inicialización directa:
let resultado = numero_1 + numero_2; // Vale 4

Reglas de Identificadores

El nombre asignado a una variable debe obedecer obligatoriamente a estas dos normas:

  • Solo puede estar formado por letras, números y los caracteres especiales $ (dólar) y _ (guion bajo).
  • El primer carácter jamás puede ser un número.
Nombres Válidos: let $numero1; let _$letra; let $$$otroNumero; let $_a_$4;
Nombres Incorrectos: let 1numero; // Empieza por un número let numero; 1_123; // Contiene un punto y coma

1.8.3 Tipos de Variables Primitivas

1.8.3.1 Numéricas

Almacenan valores enteros o decimales. Los decimales utilizan siempre el carácter . (punto) en vez de coma como separador: 

let iva = 16;          // Entero
let total = 234.65;    // Decimal (punto flotante)

1.8.3.2 Cadenas de Texto o Strings

Almacenan palabras, caracteres o textos completos encerrados entre comillas dobles (") o simples ('): 

let mensaje = "Bienvenido a nuestro sitio web";
let nombreProducto = 'Producto ABC';
let letraSeleccionada = 'c';
Comillas anidadas y Mecanismo de Escape

Cuando el propio texto contiene comillas o saltos de línea, podemos alternar comillas simples/dobles o utilizar la barra inclinada invertida (\) como carácter de escape:

Si se desea incluir... Secuencia de escape Descripción
Una nueva línea Salto de línea en cuadros alert o cadenas
Un tabulador Espaciado horizontal tabular
Una comilla simple'Permite incluir ' dentro de un string delimitado por '
Una comilla doble"Permite incluir " dentro de un string delimitado por "
Una barra invertida\Permite imprimir el carácter \ literal

let texto2 = "Una frase con "comillas dobles" dentro";
let multiLinea = "Primera línea
Segunda línea con tabulación:	OK";

1.8.4 Booleanos (Tipos Lógicos)

Una variable de tipo boolean almacena exclusivamente uno de dos valores posibles: true (verdadero) o false (falso). Es la base para la toma de decisiones lógicas: 

let clienteRegistrado = false;
let ivaIncluido = true;

1.8.5 Conversiones entre Tipos Simples (Coerción y Parseo)

En muchas situaciones es imprescindible transformar un tipo simple en otro (por ejemplo, convertir texto recibido de un formulario o prompt() en un número real con el que realizar cálculos matemáticos):

Función Acción Ejemplo Resultado
Number(dato) Convierte a número general (entero o decimal) Number("32.5") 32.5 (número)
parseInt(cadena) Parsea y extrae la parte entera parseInt("42 px") 42 (entero)
parseFloat(cadena) Parsea un número con parte fraccionaria parseFloat("3.1416 rad") 3.1416 (real)
String(dato) Convierte cualquier valor a texto String(23) "23" (cadena)
Boolean(dato) Evalúa la veracidad (truthy/falsy) Boolean("true") true (booleano)
Aplicación directa con prompt()

Todo lo introducido por un usuario en un prompt() llega a JavaScript como cadena de texto. Si el usuario escribe "32" y queremos sumarle 5, haríamos: 

let numeroTexto = prompt("Dime un número:");
let doble = parseInt(numeroTexto) * 2;
alert("El doble es " + doble);
El Valor Especial: NaN (Not a Number)

Si intentamos convertir a número una cadena incompatible o realizamos una operación matemática inválida (como operar con undefined), JavaScript produce el valor especial NaN. 

let valorInvalido = parseInt("hola"); // Produce NaN

// Comprobación con la función isNaN():
if (isNaN(valorInvalido)) {
    alert("El valor introducido no es numérico");
}

1.8.6 Operadores en JavaScript

Los operadores permiten realizar cálculos, manipular variables y evaluar condiciones lógicas complejas:

1.8.6.1 Asignación (=)

Guarda un valor en una variable. A la izquierda siempre figura el identificador, y a la derecha el valor o expresión evaluada: 

let numero1 = 3;
let numero2 = 4;
numero1 = 5;        // Ahora numero1 vale 5
numero1 = numero2;  // Ahora numero1 vale 4
1.8.6.2 Incremento y Decremento (++ / --)

Aumentan o disminuyen en una unidad el valor de una variable numérica. La posición del operador cambia el resultado devuelto en la expresión: 

let a = 1;
console.log(a++); // Imprime 1 y luego incrementa "a" (ahora a vale 2)
console.log(++a); // Incrementa "a" primero (vale 3) y luego imprime 3
1.8.6.3 Operadores Lógicos (!, &&, ||)

Operan sobre valores booleanos y devuelven siempre un resultado booleano (true o false):

Negación (!)

Invierte el valor de verdad:

  • !true $ ightarrow$ false
  • !false $ ightarrow$ true
AND Lógico (&&)

Solo es true si ambos lo son:

  • true && true $ ightarrow$ true
  • true && false $ ightarrow$ false
  • false && ... $ ightarrow$ false
OR Lógico (||)

Es true si al menos uno lo es:

  • true || false $ ightarrow$ true
  • false || true $ ightarrow$ true
  • false || false $ ightarrow$ false
1.8.6.7 Operadores Aritméticos y Coerción de Tipos

Incluyen suma (+), resta (-), multiplicación (*), división (/) y módulo (%, resto de la división entera): 

// Módulo (%)
let r1 = 10 % 5; // 0 (división exacta)
let r2 = 9 % 5;  // 4 (resto de 9 / 5)

// Coerción aritmética automática de JavaScript:
console.log(4 * 6);                // 24
console.log("24" / 12);            // 2 (convierte "24" a número)
console.log("42" * true);           // 42 (true se convierte en 1)
console.log("42" * false);          // 0 (false se convierte en 0)
console.log("42" - null);           // 42 (null se convierte en 0)
console.log("42" * undefined);      // NaN
console.log("Hello " * "world!");    // NaN
console.log(13 * 10 - "12");       // 118

// Asignación compuesta:
let n = 5;
n += 3; // 8
n -= 1; // 7
n *= 2; // 14
n /= 2; // 7
n %= 4; // 3
1.8.6.8 Operadores Relacionales (== vs ===)

Comparan dos operandos y devuelven un booleano. La diferencia fundamental en JavaScript radica entre igualdad abstracta e igualdad estricta:

Operador Comparación Diferencia de Tipo
== / != Igualdad / Desigualdad débil No tiene en cuenta los tipos: convierte automáticamente los datos antes de comparar.
=== / !== Igualdad / Desigualdad estricta Comprueba valor y tipo idénticos. Si difiere el tipo, devuelve falso directamente. 
console.log(3 == "3");             // true (valores equivalentes tras conversión)
console.log(3 === "3");            // false (uno es Number y el otro String)
console.log(3 != "3");             // false
console.log(3 !== "3");            // true

// Reglas especiales del lenguaje:
console.log(null == undefined);     // true (regla especial de JavaScript)
console.log(null === undefined);    // false (tipos distintos)
console.log(0 == false);            // true
console.log(0 === false);           // false
console.log([] >= false);           // true
console.log({} >= false);           // false
1.9

Estructuras de Control de Flujo

Las estructuras de control permiten alterar la ejecución lineal de un script para tomar decisiones dinámicas y repetir secuencias de código según el estado de las variables.

1.9.1 Estructura if

Evalúa una condición lógica entre paréntesis. Si el resultado es true, se ejecutan las sentencias encerradas entre las llaves { ... }: 

let mostrarMensaje = true;
if (mostrarMensaje === true) {
    alert("Hola Mundo");
}
¡Cuidado! El fallo más recurrente en principiantes es confundir el operador de asignación (=) con el de comparación (== o ===).

1.9.2 Estructura if...else

Permite bifurcar en dos caminos excluyentes: si la condición es cierta se ejecuta el primer bloque, y si es falsa se ejecuta el bloque posterior a else: 

let edad = 17;
if (edad >= 18) {
    alert("Acceso permitido: mayor de edad.");
} else {
    alert("Acceso denegado: debes ser mayor de 18 años.");
}

1.9.3 Estructura switch

Especialmente útil cuando una misma variable debe compararse frente a múltiples valores concretos, evitando una cadena excesiva de else if: 

let metodoPago = "tarjeta";

switch (metodoPago) {
    case "efectivo":
        console.log("Pagará en la entrega.");
        break;
    case "tarjeta":
        console.log("Conectando con la pasarela bancaria...");
        break;
    case "bizum":
        console.log("Introduce tu número de teléfono móvil.");
        break;
    default:
        console.log("Método de pago no reconocido.");
}

1.9.4 Estructura for

Estructura de bucle clásica gobernada por tres partes: for (inicialización; condición; actualización). Se repite mientras la condición sea verdadera: 

let limit = 5;
for (let i = 1; i <= limit; i++) {
    console.log(i); // Imprime: 1 2 3 4 5
}

// Recorrido clásico de un Array con for:
let dias = ["Lunes", "Martes", "Miércoles", "Jueves", "Viernes", "Sábado", "Domingo"];
for (let i = 0; i < dias.length; i++) {
    console.log(dias[i]);
}

1.9.5 Estructura while

Evalúa la condición antes de cada repetición. Si la condición es falsa desde el principio, el bloque no se ejecutará ninguna vez: 

// Suma acumulada de los números menores o iguales a 5 (1 + 2 + 3 + 4 + 5 = 15):
let resultado = 0;
let numero = 5;
let i = 1;

while (i <= numero) {
    resultado += i; // Equivale a: resultado = resultado + i;
    i++;            // Imprescindible actualizar la variable de control para evitar bucle infinito
}
alert("Suma acumulada: " + resultado);

1.9.6 Estructura do...while

A diferencia del bucle anterior, la condición se comprueba al final, por lo que las instrucciones se ejecutan siempre al menos una vez. Es obligatorio terminar con punto y coma: while (condición);. 

// Cálculo del factorial de 5 (5! = 5 * 4 * 3 * 2 * 1 = 120):
let factorial = 1;
let n = 5;

do {
    factorial *= n;
    n--;
} while (n > 0);

alert("El factorial es: " + factorial);

1.9.7 Sentencias break y continue

Permiten manipular el flujo normal de cualquier bucle (for, while o do..while):

break (Interrupción Definitiva)

Termina abruptamente el bucle y traslada el control a la siguiente línea externa:

for (let val = 1; val <= 5; val++) {
    if (val === 3) {
        break; // Se detiene al llegar a 3
    }
    console.log(val); // Imprime: 1, 2
}
continue (Salto de Iteración)

Omite el resto del cuerpo en la vuelta actual y salta de inmediato a la siguiente:

for (let val = 1; val <= 5; val++) {
    if (val === 3) {
        continue; // Se salta el 3
    }
    console.log(val); // Imprime: 1, 2, 4, 5
}
