Módulo 5: PHP & MySQL Desarrollo Backend LMSGI

Programación en Servidor con PHP & Bases de Datos

Aprende a construir aplicaciones web dinámicas en el lado del servidor. Domina la sintaxis moderna de PHP 8+, la gestión de peticiones HTTP, el procesamiento de formularios, el control de sesiones y cookies, la comunicación asíncrona mediante AJAX y la conexión segura a bases de datos MySQL mediante PDO.

Comenzar con el Tema 0 Solucionario (40 Ejercicios) Descargar BD (SQL)
Arquitectura Servidor

Apache • MySQL / MariaDB • PDO • PHP 8.x

Sintaxis y Lógica Web

Variables, estructuras de control, bucles, modularidad con funciones y tratamiento avanzado de arrays.

Seguridad y Sesiones

Saneado anti-XSS con htmlspecialchars, persistencia con cookies y autenticación con $_SESSION.

BBDD Relacionales con PDO

Consultas preparadas, prevención de inyecciones SQL (SQLi) y operaciones CRUD completas en MySQL.
