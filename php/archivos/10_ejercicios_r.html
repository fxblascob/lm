Tema 01 • Ejercicio 3

Evaluación de operadores de asignación, comparación y lógicos

Ver en Teoría
Enunciado de la Actividad

Solución Implementada
03_echo.php 
<?php
/**
 * Tema 01 - Ejercicio 3: Evaluación de expresiones lógicas y de asignación
 */
$num1 = 3;
$num2 = 5;
$num3 = 8;
$num1 *= 4; // $num1 pasa a ser 12

echo $num1; // Imprime: 12
echo "<br>";

echo $num1 <= $num2; // 12 <= 5 es falso -> echo de booleano false no muestra nada en pantalla (vacío)
echo "<br>";

echo $num3 > $num1 and $num3 > $num2; // 8 > 12 es falso -> echo false no muestra nada
echo "<br>";

echo "<br>";

echo "<br>";

echo "<br>";
?>

Tema 02 • Ejercicio 3

Paso de parámetros por referencia (&) para modificar variables

Ver en Teoría
Enunciado de la Actividad

Crea una página llamada 03_intercambia.php en la carpeta de ejercicios. Añade dentro una función llamada intercambia que reciba 2 parámetros numéricos por referencia, y lo que haga sea intercambiar sus valores. Es decir, si recibe el parámetro $a y el $b, debe hacer que $a tome el valor de $b, y $b tome el valor de $a.

Solución Implementada
03_intercambia.php 
<?php
/*
Crea una página llamada 03_intercambia.php en la carpeta de ejercicios. Añade dentro una función llamada intercambia que reciba 2 parámetros numéricos por referencia, y lo que haga sea intercambiar sus valores. Es decir, si recibe el parámetro $a y el $b, debe hacer que $a tome el valor de $b, y $b tome el valor de $a.
*/
    function intercambia(&$a,&$b)  {
        $aux = $a;
        $a = $b;
        $b = $aux;
    }
    $a = 10;
    $b = 20;
    echo ("<h1> Antes del intercambio  \$a = $a Y \$b= $b</h1>");
    intercambia($a,$b);
    echo ("<h1> Después del intercambio \$a = $a Y \$b= $b</h1>");
?>
Explicación Didáctica y Buenas Prácticas

Al anteponer el ampersand & en la declaración de parámetros (function intercambia(&$a, &$b)), la función recibe la dirección de memoria de las variables originales, permitiendo alterar su valor fuera del ámbito de la función.
